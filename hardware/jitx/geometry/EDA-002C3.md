## HRO: independent layout transcription

The exact drawing explicitly defines a recommended component-side PCB layout.
Its local PCB tolerance is ±0.05, taking precedence over the general title-block
mechanical tolerances for this layout. Copper, drills, and contacts must be read
from that layout, not the adjacent component mechanical views.

Choose origin at the midpoint of locating holes, x rightward, y toward the
contact row. This is the accepted JITX model's frame. To express frozen local
values in that comparison frame use `x = frozen pcbX`,
`y = -(frozen pcbY + 2.60)`. This reflection normalizes the row direction
for dimension comparison; it is **not** an implemented placement transform or
proof that labeled physical orientation matches between tools.

The layout gives opposing center spans 6.40 (outer wide contacts), 4.80
(inner wide contacts), 3.50 and 2.50 (signal contacts), and 0.50 signal pitch.
Divide symmetric spans by two and continue the pitch inward to obtain the
following full contact inventory. Each row's manufacturer/JITX y is 1.07;
each frozen normalized y is 1.445.

### Reviewable JITX density-C derivation

Actual installed versions are JITX 4.4.3 and jitxlib-standard 4.4.0, unchanged.
`SONLead` selects `SmallOutlineNoLeads`; its C fillets are toe=0.20,
heel=0, side=-0.04, courtyard excess=0.10. `compute_ipc` implements an
IPC-7351B-based formula with fabrication tolerance F=0 and placement accuracy
P=0. This is a disclosed tool approximation. The IPC text was not independently
licensed/read; this report verifies the installed implementation and numerical
derivation, not full compliance with every IPC requirement. Generator file
hashes are in `evidence/geometry-observation.json`.

Use lead span 2.90–3.10, length 0.40–0.50, width 0.20–0.30:

```text
CL = 3.10 - 2.90 = 0.20
CT = 0.50 - 0.40 = 0.10
CW = 0.30 - 0.20 = 0.10
Smax = 3.10 - 2*0.40 = 2.30
CS = sqrt(CL² + CT²) = 0.223606797749979
Z = 2.90 + 2*0.20 + CL = 3.50
G = Smax - 2*0 - CS = 2.076393202250021
X = 0.20 + 2*(-0.04) + CW = 0.22
land length = (Z-G)/2 = 0.711803398874990
column center span = G + land length = 2.788196601125010
column centers = ±1.394098300562505
```

The eight public JITX pad observations reproduce these results. Central copper
0.20 × 1.60 is explicitly requested by the component model from nominal
D1/E1, **not** calculated by the signal-land IPC formula. Nominal metal size
alone does not validate PCB soldermask, paste, assembly tolerance or stencil
coverage. Density C is also a design-policy choice, not a manufacturer mandate.
