Work-in-progress free and open-source topological (rubberband) router and autorouter for printed circuit boards (PCBs)

Usage: topola [OPTIONS] <SPECCTRA DESIGN FILE>

Arguments:
  <SPECCTRA DESIGN FILE>  Specify the Specctra Design (*.dsn) input file for the Topola autorouter

Options:
  -o, --output <SPECCTRA SESSION FILE>  Specify the output session file in Specctra-compatible format (*.ses). The input filename is used by default, with the extension changed to Specctra Session File extension
  -c, --commands <COMMAND FILE>         JSON-like file with .cmd extension, containing sequence of available commands 
  -h, --help                            Print help
  -V, --version                         Print version
