# Issue #121 指示書 — 完全自動配線を実現する条件の探索

## 目的
PO方針：自動ルーティングは強い要望であり、4層化以外の制約は緩めてよい。**完全自動（手直しなし）で Rev.M1 Main が完成する最小の条件を見定める**ことが目的。見つけた条件と基板価格を材料に、手動配線を取り入れるかを PO が判断する。本Issueは探索であり、正式な設計ルール変更ではない。

## 起点と固定条件
- 起点の実測：#119 セルB（KRT × 4層 × 0.127mm × ビア0.60/0.30、escalation off）で未配線1件。残件は U1.48/U1.49 のみを含む V3V3 島と主電源島の未接続（出典：docs/issue-119-promising-tools-relaxed-conditions.md）
- 入力は #119 の資産を再利用する（4層 native／DSN／smoke、等価性証明済み）。hash を再照合し、出典を明記する
- 固定：4層構成（F.Cu信号／In1.Cu GNDプレーン／In2.Cu信号／B.Cu信号）、配置、部品、ネット、板厚1.2mm、KRT v0.23.8（#113〜#119 と同一固定）
- ツールは KRT に絞る（fab_router は緩和で改善しないことが #119 で実証済み、Freerouting は幅違反を伴うため）

## 探索セル（この順に実施。完成したら残りは実施しない）
寸法変更は入力側で行い、「ルール値以外の差分ゼロ」を各セルの等価性ゲートで確認してから実行する。KRT の CLI では幅・クリアランス・ビアを明示固定し、実効設定を読戻す。

- **セル1**：幅／クリアランス **0.10mm**、ビア 0.60/0.30mm、escalation off
- **セル2**：幅／クリアランス 0.127mm、ビア **0.45/0.20mm**、escalation off
- **セル3**：幅／クリアランス **0.10mm**、ビア **0.45/0.20mm**、escalation off
- **セル4**：escalation（fab）**有効**、ベースは 0.127mm／ビア0.60/0.30。ツールが選んだ緩和を**ネット別に抽出**する（各ネットの実績の幅・クリアランス・ビア寸法）。均一条件で届かない場合の「何がどこまで必要か」の地図が成果物

## 判定と停止規則
- 判定は独立4指標（必須未接続／異ネット接触／物的違反／説明不能な転送変更）。全て「検査を実行した上で0」で完成。未配線が残れば null
- 完成セルが出たら、そのセルを最終とし、残りのセルは実施しない。レポートで「確認された最小の完成条件」を明示する
- どのセルも完成しない場合は、最も近いセルと残接続の内訳、セル4のネット別ティア地図をもって「完全自動に必要な条件の輪郭」として報告する
- 結果を見てからの未宣言の設定変更・再実行は禁止。セルの追加はしない

## 記録項目（全セル共通）
未配線数とネット／端点、幅の実分布、ビアの実分布、層別トラック数、実行時間、停止理由、出力プロジェクトの全差分（下限の書き戻しはセル4では想定内だが、内容を全て記録する）。未完成でも DRC 生値を保存する。smoke は対応条件の入力で各セル前に通す（4指標0）。

## レポート（docs/issue-121-full-auto-conditions.md）
- 結論を冒頭に：完全自動が確認できた条件（または「均一条件では未確認」＋ティア地図の要約）
- セル別結果と比較表（#119 セルB を含む）
- 完成条件がある場合、その条件の製造上の位置づけを事実ベースで整理する（例：0.10mm は JLCPCB 多層の標準能力内か、ビア 0.45/0.20 の扱い）。価格の断定はしない（見積もりは PMO が別途取得する）。出典を添える
- 事実・実測・推定を区別する
