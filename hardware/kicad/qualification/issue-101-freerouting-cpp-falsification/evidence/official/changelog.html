ChangeLog

The current release is 2.0.1 (September 2026). Source is the tarball next to that entry. There is no separate public Git repository.

Version 2.0.1 (2026-10)

  • the autorouter is new and no longer uses the maze search of the Java program; fanout, routing passes and the postroute optimizer are described under How the Autorouter Works,
  • --angle 90|45|any sets the snap angle in the window and for --autoroute,
  • --no-postroute skips the optimizer after --autoroute,
  • memory use of autoroute and the optimizer stays bounded for the whole run,
  • the mouse wheel zooms while autoroute or the optimizer is running,
  • the window translations (German, French, Spanish, Italian, Russian, Japanese, Chinese) use the board terms of the program,
  • source code: freeRouting-2.0.1.tar.gz.

Version 2.0.0 (2026-09)

  • C++ and Qt port of the Java 1.3.2 code (native freeRouting binary, no Java runtime),
  • faster than the Java application,
  • leaves Java behind: successive Java releases kept changing APIs and dropping older interfaces, which repeatedly broke the program,
  • how to compile: Building from Source,
  • source code: freeRouting-2.0.0.tar.gz.
