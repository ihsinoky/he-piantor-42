# Issue #117 指示書 — 4層化の検証（Main本試験＋Wing予備見通し）

## 目的
D-012（2層基準）の改定判断材料を作る。PO方針（2026-11-04）：4層化を本命として進める。
本Issueは要求変更そのものではなく、「4層化すれば現行ルール（0.20mm）のまま Main が完成するか」の検証と、Wing の予備見通しの整理である。`docs/decisions.md` は編集しない（判断は PO の Human Gate）。

## 前提・固定条件
- 対象 Main：#113／#115 で使用した native 基板と同一（SHA256 で同定すること）
  - Main PCB: `46676e57e9618940a33c5e298244e97aaec61498a87aa7c58a264e444fc71e20`
  - Smoke PCB: `3f70465774f577ffe803f88de017004d164f045e6415ade22766a461a2454bec`
  - Project: `a5bc2aea160cc9a8b3035f77f0167c26a1de7ffdb749740c94fb7a9e9a3c87d5`
- 4層構成：F.Cu＝信号／In1.Cu＝GNDプレーン（全面ゾーン、ネットGND、充填済み）／In2.Cu＝信号／B.Cu＝信号。板厚は合計1.2mm維持。誘電体厚などの仮定は明示記録する（配線評価の範囲では仮定でよい）
- 配置・フットプリント・パッド・ネット・基板外形は2層入力と完全同一。既存トラック（Main 元3本・smoke 元1本）は元の層に保持
- ルール：幅／クリアランス 0.20mm、ビア外径0.60／drill 0.30mm を**明示固定**する。ツールの内部ティア・既定値に委ねない
- 判定：独立4指標（必須未接続／異ネット接触／物的違反／説明不能な転送変更）。全て「検査を実行した上で0」のときのみ合格。未配線が残る場合は null のまま

## Stage 0（ゲート）：入力準備と等価性
1. 2層 native 基板から4層入力を構築する（Main・smoke 両方）。手順と生成物を証跡に残す
2. 等価性ゲートを**配線実行前に**完了させる（#113 の事後照合の轍を踏まない）
   - フットプリント／パッド／ネットの棚卸しが2層入力と一致
   - 幾何差分が「層構成の追加＋GNDゾーン」に限定される
   - 4層基板から DSN を再生成し、層名・層役割・ネット・パッド位置の読戻しが一致
3. 各ルーターが層役割（In1＝プレーン）を受理するかスモークで確認する
   - プレーン層を信号層として配線してしまう等、役割を守れないルーターは、その場でそのルーターの線を止めて Stage 0 の所見として報告する。4信号層への読み替えは行わない
4. スモーク合格条件：headless 実行・出力生成・KiCad 読戻し・4指標0

## Stage 1：Main 本試験（各1回のみ）
- セルA：fab_router（#103 と同一ソース・同一APIデフォルト相当の起動方法。ソースは hash 照合）。入力は4層 DSN
- セルB：KiCad Routing Tools v0.23.8（#113／#115 と同一固定）。`--escalation off`、幅・クリアランス・ビア寸法を明示固定し、実効設定の読戻し差分を記録。出力 `.kicad_pro` の下限書き戻し（緩和方向）がないことを確認
- 記録項目：未配線数とネット／端点リスト、幅分布、ビア分布、層別トラック数とプレーン接続状況、実行時間、停止理由
- 独立検査：KiCad 読戻し時にゾーン再充填を行ってから接続検査する（プレーン接続は再充填後に数える）。未完成でも DRC 生値を保存する
- 結果を見てからの設定変更・再実行は禁止。インフラ障害による中断のみ、記録した上で1回だけ再実行可（#105 の前例どおり）

## Wing 予備見通し（配線実行はしない、分析のみ）
- 調査対象：`hardware/rev-m1/`（architecture.md、main-wing-interface.md、evaluation-plan.md、dfm-policy.md）、`docs/decisions.md` の D-015／D-017、その他 Wing の設計定義があればそれ
- **禁止：`hardware/layout/**` は消費しない**（D-015 の指示）
- 整理する内容：
  - ピッチ 17.0／16.5／16.0mm それぞれでの21キー Wing の概算サイズと、JLCPCB 低価格領域（100×100mm）との関係
  - Wing のネット構成（ホール素子信号、TMUX1208×3、Main とのインターフェース信号）と密度の見立て。Main との比較
  - 2層・0.20mm での配線見通し（楽観・悲観の根拠を分けて）。4層化や緩和が効きそうな箇所があるか
  - 本格的な配線テストを行う場合に必要な入力（何が未設計・未決定か）
- 事実・実測・推定を区別し、出典（ファイルパス）を必ず添える
