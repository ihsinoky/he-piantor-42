## 目的

KiCad Routing Tools（KRT）は .kicad_pcb を直接読み書きする KiCad ネイティブのルーターで、DSN/SES には対応しない。保守は候補中最活発（リリース30件、最新 v0.23.8）で、外部比較（FabPlane、KiCad 判定）では whole-board 6/6。本件は経路例外のもとで、同一基板・同一固定条件での実力を判定する。

## 対象と導入

- 公式リポジトリ https://github.com/drandyhaas/KiCadRoutingTools を取得する。リリース v0.23.8 で固定するか、使用コミット SHA を記録する。MIT ライセンス
- 実行形式は公式 README のデフォルト呼び出し `python3 py_router/route.py in.kicad_pcb out.kicad_pcb ...` を一次資料（README・help）で確定し、証跡に残す。デフォルト条件の特定は fab_router #103 と同様に、README・ソースから裏付ける
- KRT 同梱のチェッカ（DRC・接続性等）は自己判定であり、合否には使わない。記録する場合も独立検査と区別する

## 入力の固定と等価性ゲート（本件固有）

これまでの固定入力は DSN だった。本件の入力は .kicad_pcb であり、以下の手順で固定する。

1. 候補基板の特定：Main は #87 の証跡 `hardware/kicad/qualification/issue-87-native-main-routing/` 配下の .kicad_pcb（例：evidence/processes 配下の main.kicad_pcb）から、corrected.dsn の生成元に相当するものを特定する。特定の根拠を文書に書く
2. ハッシュ固定：採用した基板ファイルを SHA256 で固定し、証跡に保存する
3. 等価性確認：採用基板と corrected.dsn（Main: SHA256 `75b44553bf6c8cab8c7dba411ad83b11fd12b5416cd24055aa5b1a412fd54bb2`、smoke: `7214a0299ce19fae8163fa82a7d844e71c5bbf43b077392cfff7c7b5a9d1f3e9`）との間で、次が一致することを確認する
   - フットプリントの配置（位置・回転・表裏）と個数
   - ネット一覧と各パッドのネット割り当て、端子総数
   - 設計ルール：配線幅・クリアランス 0.20mm、2層（signal layers）
   - 既存配線の有無と内容（DSN に含まれる既存線分が基板側にもあるか）
4. **ゲート**：等価性が確認できない場合はルーティングを実行せず、不一致の内容を報告して止まる。基板側を勝手に修正して等価に仕立てることは禁止（入力のすり替えになる）。DSN と基板で表現が違うだけの項目（単位・丸め等）は、差異として列挙し、実質的に同一と判断した根拠を書く

スモーク基板も同じ手順で特定・固定・等価性確認を行う。

## 固定条件

- 配置固定、配線幅・クリアランス 0.20mm、2層。条件の緩和・変更は禁止

## 実行手順（二段構え）

### Stage 0（スモーク）
- 固定したスモーク基板のコピーに対して、公式デフォルト条件で1回実行する
- 出力基板に対して独立検査（下記）で4指標すべて0を確認する。失敗したら Main に進まない

### Stage 1（Main）
- 固定した Main 基板のコピーに対して同一条件で1回だけ実行する。オプション追加による調整はしない（設定探索禁止）

## 独立検査（基板直接検査への適用）

従来の独立検査（#87 以来の check-import 系 oracle）は SES import 後の基板を対象にしていた。本件では出力基板そのものを対象に、同じ4指標を測る。

- required unconnected：KiCad DRC の unconnected_items 等、従来と同じ数え方
- wrong-net contacts / material violations：KiCad DRC と従来 oracle の観点で測定
- unexplained transfer changes（本件定義）：入力基板と出力基板の差分のうち、配線（トラック・ビア）の追加 **以外** の変更。フットプリントの移動・回転・削除、基板外形、ネット定義、非配線要素（シルク・ゾーン等）の変更があれば、説明可能性によらず列挙し、合否は「説明のない変更があるか」で判定する。入力に既存配線がある場合、その保持・変更も差分対象に含める
- 幅の静的実測：出力基板の全トラック幅を列挙し、0.20mm 未満がないことを確認する（#97 以降の方式を基板に適用）

## 判定

成功条件（すべて）：
- 未配線 0
- 出力基板の全トラックが 0.20mm 以上
- 独立検査で4指標すべて 0

失敗条件（いずれか1つ）：
- 未配線が残る／0.20mm 未満のトラックがある／配線追加以外の説明のない差分がある／headless 実行不可／入力の等価性が確認できない／2時間内に結論が出ない

4指標の扱い：未配線が残る場合は **null** とし、未配線件数を実測報告する
