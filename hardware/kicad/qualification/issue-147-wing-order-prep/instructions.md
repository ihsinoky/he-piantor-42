# Issue #147 指示書：Wing 素基板の発注準備

- 発行：PMO（2026-11-05）。PO 決定済みの計画（Wing は PCBA せず、素基板を両ピッチ発注）の実行準備。発注そのものは PO ゲート
- ワーカー：Codex
- タイムボックス：**2時間**

## 前提

- Wing は PCBA しない。ホールセンサ等は部品単品で購入し手はんだする。素基板は 16mm／17mm 両ピッチを各5枚発注し、実測してから量産ピッチを確定する（2026-11-04 PO 決定）
- 発注対象の配線は D-021 改定条件（信号 0.10mm／電源 HALL_5V・GND 0.30mm、2層、1.2mm、ビア 0.60／0.30mm、クリアランス 0.10mm）で Issue #141 が合格させた出力基板（`hardware/kicad/qualification/issue-141-wing-power-integrity/` の証跡内）。#131 の一律 0.10mm 出力は使わない
- Issue #138 の報告書に発注前チェックリストがある（「済」「未」の区別つき）。本 Issue はその続き

## 作業内容

### 1. 製造データの生成
- #141 の合格出力基板（両ピッチ）から、JLCPCB 提出形式の製造データ（Gerber 一式＋Excellon ドリルファイル）を生成し、zip にまとめる
- 生成に先立ち、出力基板が製造に必要な要素を備えているか確認する：Edge.Cuts 外形、NPTH（φ2.2mm×4）、ソルダーマスク、シルク、ペースト層の要否（手はんだ前提のため、ステンシルは発注しない想定。基板データとしてペースト層がどうなるかは記録する）
- 不足や不整合があれば、勝手に設計変更せず、内容と対処案を報告する（入力基板の構築側の問題か、エクスポート設定の問題かを切り分ける）

### 2. 発注前チェック（#138 チェックリストの「未」項目のうちデータ側で完結するもの）
- 最終製造データと #141 合格基板の一致（外形・穴・最小間隔 0.10mm・ドリル分類）
- Gerber プレビュー（ビューアでの描画確認）で両ピッチを目視相当に確認し、欠落レイヤーや異常な図形がないこと
- 注文時に指定すべき製造条件の注記：2層、板厚 1.2mm、外層銅箔 1oz、ビア 0.60／0.30mm
- Keyboard Design 加算については、自己判定（非該当、#138）を引き継ぎ、確定はメーカーのファイル審査であることを明記する。メーカーサイトへのアップロードは行わない

### 3. 発注直前の残件一覧
- PO が発注に進む際に残る事項を一覧化する：メーカー審査で確定する加算の有無、送料・税を含む最終金額、注文画面での入力事項、基板以外の手配（センサ等の部品購入は別件であることも明記）
