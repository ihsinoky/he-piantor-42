# Wing素基板：両ピッチの製造データと発注前チェック

Closes #147

#141合格出力（信号0.10mm／電源・GND 0.30mm）からの16mm・17mm製造データを引き継ぎ検証し、各5枚の素基板発注用Gerber＋分離Excellon ZIPを追加。既存エクスポート・DRCは保持し、全銅箔／外形／穴／マスクの解析照合、オフライン描画、ZIP照合を完了した。既存ファイルの変更なし。

入力には両面シルクがないため、無印の受入れまたは別改版をPO／設計担当に残す。#138の未項目について、データ側の完了範囲と、メーカー加算・送料／税込み最終金額・注文欄・電源／ADC実機検証等の残件を報告書に明記した。2層・1.2mm・外層1oz、PCBA／ステンシルなし。部品購入は別件。

検証：既存45,864パス＋再開時70成果物のhash不変、#141ソース／プロジェクトbyte一致、最終DRC両ピッチ違反0／未配線0、Gerbonara全製造図形照合、PTH196／198・NPTH各4、両ピッチ9ファイルの描画確認、ZIP CRC／全メンバーhash、JSON／Python構文・参照・追加のみ差分を監査。
