# Connector evidence

Selection: JST **SM14B-GHS-TB(LF)(SN)**, LCSC/JLCPCB C265343.

- Manufacturer current catalog: https://www.jst-mfg.com/product/pdf/eng/eGH.pdf — page 2 assembly layout: side-entry mated height **(4.35)** and axial length **(7.15)**, horizontal wire exit; page 3 lists SM14B-GHS-TB and GHR-14V-S. - [stock.json](stock.json) and compressed raw HTML contain the direct HTTP observations on 2026-11-13. Search-engine cached stock was deliberately not used. LCSC 504; JLCPCB `overseasStockCount` 1859 and separate `canPresaleNumber` 1196, not additive or a reservation. Thirty headers including spares require a preferred stock of about 300; both reported stock fields exceed this. No purchase or factory acceptance is implied.

Both cable ends use standard **GHR-14V-S** and **SSHL-002T-P0.2**. This study changes Main J2/J3 to SM14B-GHS-TB as well; both Main and Wing use side-entry GH headers. Specify fourteen individual AWG28 conductors (at least 0.0804 mm²), each insulation OD <=1.0 mm, six independent return conductors, no substitution with AWG30. Use a harness fabricator's GH-compatible tooling; continuity test every cavity 1→1 through 14→14 and label L/R. No crossed/reversed wire order is allowed. Hand crimps require appropriate tooling and pull/retention checks. Actual assembled height/exit and conductor dressing still require sample measurement before manufacture.
