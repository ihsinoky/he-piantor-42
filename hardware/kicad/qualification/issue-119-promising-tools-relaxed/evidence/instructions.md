# Issue #119 指示書 — 有望ツール × 価格無料の条件緩和（4層＋0.127mm）

## 目的と位置づけ
PO指示（2026-11-04）：これまで検討してきたツールの中で有望なものを選び、試す。
#117 で「4層・0.20mm」では両候補とも完成しなかった。本Issueは、価格に追加影響のない緩和（0.127mm は JLCPCB 2層・4層とも fine-trace 追加料金なし帯域、4層化は5枚で +$4）を全て適用した条件で、有望ツールが Main を完成できるかを測る。D-012／設計ルールの正式な変更ではなく、判断材料のための測定である。

## 選定ツール（PMO選定の根拠）
- **fab_router**：厳密条件での最良実績（2層・0.20mm で未配線16件）。自己申告が正直で証跡が安定
- **KiCad Routing Tools v0.23.8**：接続性は全候補中最良（#113、ただし escalation の違反込み）。活発に保守されている。escalation off で使う
- **Freerouting v2.5.0（JAR）**：最も実績のある汎用ルーター。ただし試したのは 2層・0.20mm（38件）だけで、改善条件では未試行

## 固定条件
- 対象 Main は従来どおり（配置・部品・ネット不変）。2層入力は #113／#115 の固定入力（Main PCB SHA256 `46676e57e9618940a33c5e298244e97aaec61498a87aa7c58a264e444fc71e20`）、4層入力は #117 で検証済みの生成物（4層 native `33f079d07bfb2dad9a76dce0667a1fd1371c94406df16f36ae17fe559d74af01`、4層 corrected DSN `661d00c7d99adc270314a1a4940e64838999b948471f4d36a17aa9eac4d5e7f2`）を hash 再確認の上で再利用する
- ルール：幅／クリアランス **0.127mm** を一様適用。ビアは標準 **0.60/0.30mm** を維持し、明示固定する（小径ビアは追加料金側なので使わない）
- 0.127mm 化は入力側で行う：DSN 系は 0.127mm ルールで DSN を再生成（または同等の明示変更）し、KRT は native コピーのプロジェクト下限・netclass を 0.127mm にした入力＋CLI 明示固定。いずれも「ルール値以外の差分ゼロ」を等価性ゲートで確認してから実行する。ツール内部のティア・救済に寸法決定を委ねない
- 判定：独立4指標（必須未接続／異ネット接触／物的違反／説明不能な転送変更）。全て検査を実行した上で0のときのみ合格。未配線が残れば null

## セル構成（各1回、結果を見てからの設定変更・再実行は禁止）
- セルA：fab_router × 4層 × 0.127mm
- セルB：KRT（escalation off）× 4層 × 0.127mm
- セルC：Freerouting × 4層 × 0.127mm（起動構成は #95 の最良構成＝fanout／optimizer 有効の系譜で固定し、実効設定を読戻し記録する）
- セルD：fab_router × 2層 × 0.127mm（比較セル。緩和下で層が効いたかを分離するため）

## Stage 0（ゲート）
1. 0.127mm 入力（4層DSN／4層native／2層DSN／各smoke）の準備と等価性ゲート：差分がルール値と、それに伴う DSN 表現だけであること
2. smoke は対応する入力条件のものを使い、各ツールで4指標0を合格とする。#117 の smoke 資産（プレーン=N の修正済み fixture を含む）を再利用してよい
3. KRT については層別トラック数を必ず記録する（#117 で B.Cu が0本だった観察の追跡）
