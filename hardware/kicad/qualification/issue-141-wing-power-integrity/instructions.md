# Issue #141 指示書：Wing 電源インテグリティのフォローアップ

- 発行：PMO（2026-11-05）。PMO-GO 権限委譲に基づく（評価と材料作成まで。基準改定の決定は PO）
- ワーカー：Codex
- タイムボックス：**全体で3時間**

## 背景

- Issue #138 の点検（`docs/issue-138-wing-manufacturing-review-prep.md` と証跡）で判明した指摘に対応する
- Wing の全30ネットは一律 0.10mm で配線されている（#131 の合格セルは一律幅条件）。HALL_5V と GND も最小幅で、幹線の拡幅はない
- #138 の DC モデル：全21センサ同時通電・データシート表 max（5mA／個）で、最遠センサの往復降下は 16mm で 0.234V（0.08mm・20°C）。J_WING 入力 4.75V の仮定では局所電源 4.516V、高温側（125°C）では 4.419V と推奨下限 4.5V を割る。保守包絡（11mA／個）ではさらに大きい
- 電流・発熱は問題なし（最悪包絡 231mA < スクリーニング容量 383mA）。問題は抵抗と電圧降下のみ

## Stage 0：供給条件の確定

- リポジトリ内の Main 側設計データ（JITX 設計定義、回路・電源に関する文書）から次を確認する：
  - HALL_5V の供給元（どのレギュレータ／電源から来るか、定格電流）
  - J_WING コネクタでの想定電圧（5V 系か 3.3V 系か、許容変動）
  - Main→Wing のケーブル・コネクタで想定すべき抵抗（仕様があれば）
- 確定できた事実と、確定できず仮定に残るものを切り分けて記録する。仮定を使う場合は #138 と同じ感度解析の枠（入力 4.75V 等）を引き継ぎ、仮定であることを明記する
- DRV5055 の供給電流は #138 の留保を引き継ぐ：データシート RevC の表 max（5V で 5mA／個）と Fig 5-13 の不整合を踏まえ、表 max と保守包絡（11mA／個、出力負荷込み）の両ケースで評価する

## Stage 1：拡幅セルの再配線

- ツール：KiCad Routing Tools（#131 と同一バージョン／コミット）、**escalation off 固定**
- 基礎入力：#131 の Stage 0 改訂入力（keepout の pads 修正済み、等価性ゲート通過済みのもの）。配置・ネット・外形は変更しない
- ネットクラス分け：
  - 電源クラス（HALL_5V、GND）：幅 W（下記）
  - 信号クラス（残り全ネット）：幅 0.10mm（D-021 のまま）
  - クリアランスは全クラス 0.10mm。ビア 0.60／0.30mm は共通で維持
- 幅 W の候補：**0.30mm を先に1セル**。完走しなければ **0.20mm を1セル**。各セル単一 run、途中の条件調整なし
- 対象は representative21-16mm 先行。合格したら同条件で representative21-17mm を1セル確認する
- 合格基準（セルごと）：
  - 独立検査の4指標すべて 0（手順は #131 の踏襲）
  - 幅監査：信号クラスに 0.10mm 未満なし、電源クラスに指定幅 W 未満なし、出力プロジェクトの書き換えなし
- 未配線が残れば4指標は null とし、実測件数を報告する

## Stage 2：電圧降下の再評価

- #138 の DC モデル手法（`estimate-dc-drop.py` の考え方。実配線・パッド・via 位置から抵抗回路を組み、全負荷同時印加）を再配線後の基板に適用する
- 計算ケースは #138 と揃える：表 max／保守包絡 × 20°C／高温側 × 公称幅／最悪幅（電源クラスは W の −20%）
- Stage 0 で確定した供給条件と組み合わせ、最遠センサの局所電源電圧と GND 持ち上がりを示し、推奨下限 4.5V に対する余裕を両ピッチで報告する
- #138 の現行値（拡幅前）と並べて比較表にする
