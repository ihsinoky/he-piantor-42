# Issue #190 — Wing 配列 Stage 1：Cantor 原典からの再導出

21中心の u 比を確定した。**現行外形へ中心だけなら収まるが、Jade Pro の全平面包絡を基板内に収める条件では、再アンカーだけでは両ピッチとも幅不足になる。** 外形拡張を Stage 2 の前提候補とし、標準幅 DSA キャップは不採用、狭幅キャップは実寸確認を条件とする。

2026-11-07 実施。[Issue #190](https://github.com/ihsinoky/he-piantor-42/issues/190) 本文と `.issue190-runtime/instructions-190.md` 全文を読んだ。対象は Wing の Stage 1 のみ。Main、Matrix、配線、製造データは対象外。以下 E は [hardware/case/issue-190-layout/](../hardware/case/issue-190-layout/)。

## 1. 原典、単位と検証

[Cantor Classic PCB](https://github.com/diepala/cantor/blob/91b40f613f4acf94e50f08c04c11567fc2abdccf/Cantor_Classic/keyboard_pcb.kicad_pcb) と [Piantor 左 PCB](https://github.com/beekeeb/piantor/blob/237ae92738af27e34bc5353903e42a68af22f32d/pcb/left/keyboard_pcb.kicad_pcb) の固定 revision を取得し、各 footprint のトップレベル `(at)` と reference を独立に抽出した。21中心は両者・PMO転記と完全一致。原典 PCB の設計座標の抽出値であり、実物をノギス等で測定した値ではない。出典 revision／SHA-256 は E/inputs/upstream.json、抽出値は E/inputs/{cantor,piantor}-extracted.csv。GitHub connector で Issue と revision を照合したが、PCB本文の読取りは空だったため、raw.githubusercontent.com の固定 revision を runtime に取得した。

原典 KiCad 絶対座標 `(X,Y)` は右・下が正。u 原点は `(74,53) mm`（キー中心ではない）。`u=(X−74)/18`, `v=(Y−53)/17`。横18 mmと縦17 mmを別々に1uとする。18×17の実寸が16×16／17×17になるため、原典実寸の一様相似縮小ではない。以下の mm は、この規約から計算した**提案設計値**。

## 4. 外形・四隅穴・実部品包絡

維持判定の条件は、キー中心だけでなくスイッチの全平面包絡が矩形基板内に入り、φ2.2 NPTH とφ5 keepoutを避けること。キーキャップが基板端を越えるだけなら機構上認められる可能性はあるが、ここでは全キー包絡支持の条件を採る。**外周オーバーハングを別途許可する場合、中心・穴の条件から直ちに外形変更が必須とは言えない**。本提案でその許可を仮定しない。

現行穴は端から3mm。ローカル四隅は16mm：`(±52,±47)`、17mm：`(±55.25,±49.375)`。径2.2、keepout径5、基板は110×100／116.5×104.75、厚さ1.2mm。距離は基板外形中心線・穴中心から計算し、切削公差・ねじ座金の未知寸法は含めない。

Jade Pro KS-20TF10B045NW-Y106 は #150 の [Gateron 図面7頁](https://www.gateron.com/u_file/2505/21/file/GateronMagneticJadeProSwitchKS-20TF10B045NW-Y106PRO1.pdf) を保存画像で再読取した。公表上面15.40×15.10、未注記公差±0.4から **15.8角の保守包絡**で評価する。これはWingのシルクセルやHall SOT-23外形ではない。14±0.05胴体、φ1.70位置決め脚などの3D実装条件は #150 と同様別途確認が要る。キャップは [SP DSA図面1頁](https://cdn.shopify.com/s/files/1/0793/6996/1750/files/DSAFamily.pdf?v=1695018374) の実寸0.725インチ=18.415角。15.0角は狭幅キャップの**設計上限**で、実在製品の実測値ではない。画像と #150 出典記録をE/inputsに固定した。

現行「1ピッチセル＋周囲3mm＋南側18mm」をそのまま新中心範囲へ適用した必要外形は **119.777778×104／126.888889×109mm**。これは回転0セルの政策的寸法案であり、最小の物理外形ではない。この案なら同じ再アンカーでJadeは横3.1／3.6、上3.1／3.6、下21.1／21.6mmの余裕がある。拡張後も穴を端3mmとするなら穴位置が変わる。したがって「新外形」と「旧四穴XYの完全維持」を同時に決定してはいない。Stage 2 で外形・取付を再評価する。

### キー同士の干渉

全210ペアを正方形包絡の分離軸法で検査。回転0では分離余裕 `max(|dx|,|dy|)−w` と等価。円の中心間距離だけで判定しない。負値のペア数は保守包絡の重複数であり、丸隅や高さ逃げを考慮した実部品衝突数ではない。ただしDSAは同列の直交隣接で16−18.415／17−18.415の重なりがあるため、丸隅に頼って適合にはできない。

Jade の理想中心・回転0では0.2／1.2mmだが、16mmは各キー中心誤差±0.10だけで余裕を消費する。回転1°で15.8角の投影は約16.073になる。爪、工具、回転ガタ、位置公差、全押下でのキャップ裾の干渉は実物確認が必要。15角キャップの名目隙間は1／2mm、各キー横遊び0.15＋中心ずれ0.10の #150 設計予算を両側へ配ると0.5／1.5mm。市場で購入可能な適合部品の認定は行っていない。

原典thumb角度を使うと、Jade全包絡幅は116.176294／122.287405mm、現行外形をさらに超える。再アンカー候補では右端の不足4.387405／4.192960mm。φ5 keepoutへの最小包絡隙間は11.020142／11.386060mmで穴との干渉はない。先述の回転0セル外形案ならJade右端余裕は0.501484／1.001484mmまで減る。3mm外周余裕をそのまま保証する案ではない。姿勢採用時には外形政策を再決定する。

**Stage 1 判定：** 中心と穴は既存外形で成立する。キー同士はJade保守包絡で理想配置なら重複なし。全包絡を基板内へ収める条件では両ピッチとも再アンカーのみでは不可、幅変更を要する。17mmを機械評価先行候補とし、狭幅キャップ選定・姿勢決定・外形採用をStage 2前提としてPOへ渡す。外形だけの幾何学判定を電装・製造適合の承認にはしない。
