# Hardware

現行は Main Rev.4／Matrix Rev.3／Wing Rev.3。CAD・回路源、単板とパネル、
ケース入力CSVは [成果物索引](../docs/artifacts-index.md) から正本へ進んでください。
Main は UDB C3 を別基板に持ち、左右Wingへ各200mmのハーネスで接続します。
Matrix は評価用18キー基板で、製品Wingとは別です。

設計採択と実機合格・発注GOは別です。[現行状態と残件](../docs/project-status.md)を参照。
`sensor-test/`、`main/`、旧Rev.M1やEDA評価の資料は設計履歴を含みます。
