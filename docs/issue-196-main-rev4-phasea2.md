## 三角形の導出

### 120°配置の定義

組立座標は上面視、X右、Y南、mm。左 Wing のローカル座標は PR #195 の X右／Y北をそのまま使う。右は元の右専用definitionを使い、キー配置を変更しない。KiCadへ渡す際の提案変換は `X_K=100+X, Y_K=70+Y`。角度は KiCad の実回転であり、パッド／端子番号を鏡像にしない。

120°だけでは Wing の平行移動・南辺位置は決まらない。以下を**追加の機械設計提案**として明示する。完成イメージv4の独立した寸法付きCADは今回の入力にはないため、これを既承認寸法とは扱わない。

1. 「内側辺」は、左のローカル東辺／右のローカル西辺（矩形の短辺、高さ83／87mm）と定義する。
2. 両 Wing の内側北角を組立 `(-1,0)`／`(+1,0)` に合わせる。北角間隙 `g=2.0mm` は中央寄せの提案値。ピッチ変更時は基板全体をこの datum に合わせ、ローカルキー座標を維持する。
3. 左 Wing をローカルX右／Y北系で−30°、右を＋30°回す。外向き軸は組立 `(-√3/2,-1/2)`／`(+√3/2,-1/2)` なので内積−1/2、なす角は120°となる。

`c=√3/2`、左ローカル内側辺 `x=a`、北辺 `y=b` とすると、左の変換は次式。右は左右を実座標で鏡映対応させた剛体回転で、JSONに左右それぞれの行列・平行移動を保存した。

```text
X = -g/2 + c(x-a) + (y-b)/2
Y =        (x-a)/2 - c(y-b)
16mm: a=60.1, b=49.2, y_min=-33.8
17mm: a=63.1, b=51.2, y_min=-35.8
左内側辺:  cX + Y/2 + cg/2 = 0
右内側辺: -cX + Y/2 + cg/2 = 0
```

| ピッチ | 左内側辺・北端 | 左内側辺・南端 | 左 Wing J1／J_WING | スイッチ包絡の組立南限 Y |
| --- | --- | --- | --- | ---: |
| 16mm | −1,0 | −42.5,71.880109 | −121.191067,13.977034 | 67.924034 |
| 17mm | −1,0 | −44.5,75.344210 | −124.789143,14.209085 | 71.415913 |

右はX符号反転。辺の式は両ピッチで完全に同じになり、有限長だけが変わる。

### クリアランスと頂点

Wing PCB と Main 斜辺の法線間隔を **2.0mm** とする。これは回転配置・ケース公差・作業余裕への設計提案であり、壁厚やケーブル曲げの保証値ではない。係数の法線長が1なので、Main は `±cX+Y/2+cg/2≥2` の共通内部となる。頂点Yは `Y_t=2(2−cg/2)=2.267949192`。

南辺は「ケースをスイッチ包絡へ詰める」入力に合わせ、両ピッチの南限の小さい方を越えない0.1mm格子の `Y_b=floor(67.924034×10)/10=67.9` を共通採用する。ケース内面のスイッチ包絡余裕は別途0.25mmを提案する。Main のためにケース南辺をさらに伸ばす案にはしない。

| 頂点（時計回り） | 組立 X,Y mm | 提案 KiCad X,Y mm |
| --- | --- | --- |
| 北 | 0,2.267949192 | 100,72.267949192 |
| 南東 | 37.892682201,67.9 | 137.892682201,137.9 |
| 南西 | −37.892682201,67.9 | 62.107317799,137.9 |

`半底辺=(Y_b−Y_t)/√3=37.892682201mm`。高さ65.632050808、底辺75.785364402、面積2486.974443465mm²。左右鏡像対称、北頂角60°。Main の斜辺全長は約75.785mmで、Wing の有限内側辺の範囲内に投影される。

| 全PCB多角形での検証 | 16mm 左／右 | 17mm 左／右 |
| --- | ---: | ---: |
| Main → Wing 最小距離 | 2.000000mm | 2.000000mm |
| Main 南辺 → スイッチ南限の北への引込み | 0.024034mm | 3.515913mm |
| PCB重複 | 0 | 0 |

共通datumを維持する限り、Main の外形・穴・部品はピッチ変更に依存しない。Wing の平行移動datum、回転角、ケースを変更した場合まで不変と主張するものではない。

**ケース南辺の入力制約**：Wing の矩形南内角はスイッチ包絡の全体南限より16mm版で3.956075mm、17mm版で3.928297mm南へ出る。従って「ケース全体の一直線の南辺をスイッチ南限＋0.25mm」とすると、既承認の矩形 Wing PCB がケースを越える。中央 Main 前面を詰め、Wing角付近だけケース輪郭を逃がす案なら共存の余地がある。全南辺を詰めるには Wing 外形改訂等の別判断が必要であり、今回は Wing／ケースを変更しない。PCB とケース壁厚・支持物を含む成立は PMO の未決事項とする。

| 部品 | 組立 native `at` | KiCad角度 | 長手軸／ケーブル外向き単位ベクトル |
| --- | --- | ---: | --- |
| J2 左 | −15.5,43 | −120° | 斜辺に平行／(−0.866025,−0.5) |
| J3 右 | 15.5,43 | +120° | 斜辺に平行／(+0.866025,−0.5) |

BM14B-GHS-TBT(LF)(SN)を保持する。pin1を含む全padを実回転し、端子番号や電気契約を鏡像化しない。26×8予約域は斜辺から最小0.442632mm内側。外向きベクトルは各Wing側を向く。

**この品番は上面嵌合（+Z）のため、水平横出しコネクタとしては扱えない。** 本案は斜辺に沿って配置し、上面から嵌合後にケーブルを各Wing側へ曲げる案である。「斜辺から横向きに直接挿す」という要求なら既存品種のまま成立とは言えず、GH14品種変更の別判断が必要。ケース内高さ、曲げ半径、着脱の3D検証は残る。

Wing 側 J1 は PR #195 のサービス配置（左ローカル−37,−23、右+37,−23、26×8予約、上面嵌合）を使用する。

| ピッチ（左右同値） | native datum間直線 | 南内角・南辺経由の折れ線案 | ＋30mmの仮余長 |
| --- | ---: | ---: | ---: |
| 16mm | 109.603532mm | 147.435562mm | 177.435562mm |
| 17mm | 113.017846mm | 156.341316mm | 186.341316mm |

折れ線は `Main→Wing南内角→Wing南辺のJ1投影点→J1`。ケーブルのZ空間やエッジ回避を含む実経路ではなく、30mmも曲げ・高さ等への設計割当である。両ピッチ共通候補を **1:1 GH14、200mm×2本** とする。180mmでは17mm側の上記割当が足りない。既存の100mm契約は両ピッチで直線さえ満たさないので、継承可能としない。200mmの採否・線径・抵抗・供給・ADCノイズを PMO へ戻す。倍長による給電降下を旧50mΩ／4.60V判定へ流用しない。

## UDB 接続

[C3公開BOM](https://github.com/Unified-Daughterboard/UDB-C-Legacy/blob/2ecdd7e0482ecbd3ffe9af04966ab3555f7fc33c/Production/C3/BOM/Unified-Daughterboard_bom_C3.csv)はJ2を **SM04B-SRSS-TB(LF)(SN)** と指定している。[C3向けPCB側資料](https://github.com/Unified-Daughterboard/UDB-C-Legacy/wiki/PCB-side-design-resources)にも同型番と1:1ケーブルの指定がある。Wikiはアーカイブなので、pin番号と実パッド位置は保存したC3基板からも照合した。保護機能の移管は[C3設計説明](https://github.com/Unified-Daughterboard/UDB-C-Legacy/tree/2ecdd7e0482ecbd3ffe9af04966ab3555f7fc33c)のESD／PTC／TVS／CCに基づく。

Main J4の第一候補は同型の水平嵌合4pin・1.0mmピッチ品。ケーブル側候補はSHR-04V-S＋SSH-003T-P0.2（[JST SH資料](https://www.jst.com/wp-content/uploads/2021/01/eSH.pdf)参照、発注品の線径・圧着適合・図面は次段で確認）。電気1:1であることを端子番号で保証し、販売上の「reverse」表記だけでは判断しない。

| J4 pin | C3 net | Main割当 |
| --- | --- | --- |
| 1 | VCC | VBUS（C3保護後） |
| 2 | DA− | USB_DM_ESD → R4 → USB_DM |
| 3 | DA＋ | USB_DP_ESD → R3 → USB_DP |
| 4 | GND | GND |

Main J4は **(0,20)、180°**、挿入口を北へ向ける。C3実 footprint の原点は信号列中心ではなく挿入口側で、元の信号padは局所Y=−4.775mm。180°後の信号列Y=24.775mm。元原点を取り違えず、パッド・固定ランド全数を使った。幅7.3mm、挿入口前方5mmを含む予約域が三角形内に収まる。

UDB のケースdatumは未確定なので、検討用に **C3側J2=(0,−20)、0°** を提案する。C3 PCB外接は X=−9…9、Y=−36.25…−19.75（18×16.5mm、USB部品の突出は別）。両ピッチWing PCBまでの最小距離は13.104002mm。この配置ならJ4–C3 J2の直線40mm＋仮余長30mmに対して **100mm SHケーブル** を候補とする。北のH1を避ける横逃げ・上方の実経路とケースUSB開口を確認し、実datum変更時は長さを再計算する。UDBの固定穴・USBプラグ・シールド／筐体接地は未設計であり、ケース設計を本Phaseで確定しない。
