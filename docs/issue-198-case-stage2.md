# Issue #198 ケース Stage 2

Wing Rev.3 **Stage 1b** の形状で、120°・逆ハの字・X=3.5mmの左右2分割トレーを詳細化した。17mm版の組立STEP、各印刷ピースのSTEP/STL、3D GH経路、200mm時の収納包絡、検証JSONと上面図を [成果物](../hardware/case/issue-198-stage2/README.md) に収録した。16mm版も同じ生成器で再生成する。印刷・発注・基板変更・pushは実施しない。

`.issue198-runtime/instructions-198-stage2.md`を全文読了し、指定の `.issue198-runtime/git` 内で `issue-198-case-stage2` を作成した。スクラッチと追加Python依存はすべて `.issue198-runtime/` 配下。要件書の控えと入力来歴を成果物の `inputs/` に保存した。

## 方針と入力

南辺の段形状・北タブ・GH移動は機械配置に直結するため、旧外形を手直しせず、指定ブランチの形状JSONからCSVを正規化して入力する。基板の最大Yは北タブで変わっているので、Stage 1の内側北角datumと行列を明示的に引き継ぐ。キーは不変のRev.2 CSVである。トレーの底厚2mm、壁厚2mm、基板下面Z=10mm、Wing/Main厚1.2mm、UDB厚1.6mmを保持した。キャビティ輪郭のみ計算安定性のため最大0.002mmで単純化し、オフセットを0.502mmに増して公称0.5mmの逃げを減らさない。

- Wing入力commit: `bcb285eaa1105220aeba079c456bf56ca1827fb0`、`hardware/case/issue-200-stage1/geometry.json`、schema `issue200-stage1b-v1`。配線前の形状提案であり、最終CSVではない。
- Main: origin/main `90c8314be34fcaa8582df9af5814dd6f36a87d59` のRev.4最終PCBと作業コピーの保存データが同一。SHA256 `b361a5a010a3ae2b08e5858735d46a5662112af4241ef55bab50d1ba3187b123`。59部品の位置・回転を最終PCBと全数照合した。
- UDB: Stage 1と同じC3実基板、upstream `2ecdd7e0482ecbd3ffe9af04966ab3555f7fc33c`。実外形・四隅R2・穴位置を抽出する。

`--csv-dir` で最終 outline/holes/keys を差し替え、GH・経路も変わる場合は `--geometry` を更新して再生成する。CSVの列と起動方法はREADMEに記載。穴数を固定していない。

## 南辺と締結

南辺は既定で基板上面Z=11.2mmにフラッシュ。元の南端8mm帯に加えて、全キーの南側へ伸ばす領域を壁除外域にした。南辺カットの段形状、各段の角も高い壁にしない。`--palm-offset -0.5` で縁を0.5mm下げられ、正のオフセットは拒否する。高壁と手のひら領域の重複面積は0、キーキャップ包絡との壁の隙間は0.25mm以上を検証する。

Rev.3では左H1／右H3が南辺カットで除去されている。代替候補穴は基板変更の承認済み穴ではないため採用せず、残存するWing各3穴、Main3穴、UDB4穴の計13箇所をねじ止めする。旧穴の位置に空中ボスを残さない。各基板穴の内側へボスがあることを検査し、Wing穴はCSVへの逆変換でも軸一致を検証する。

Wing/Mainボスφ4.5、UDBボスφ3.5、下穴φ1.7、深さ8mm、底厚2mmを残す。MainのJ2/J3直下の支持リブも保持。PCB固定はM2×6の樹脂用ねじと厚0.5mmの絶縁座金、ねじ頭φ3.4×1.6。掛かり長さはWing/Main 4.3mm、UDB 3.9mmで、先端は底に達しない。ねじ山はモデル化せず芯径φ1.6で表現している。UDBは4本ともナイロンねじ・絶縁座金・印刷樹脂座とし、MH2のGND PTHに金属締結を当てない。材料の耐クリープ性・下穴の実物保持力は造形後の確認事項。

接合板は28×16×3mmをY=−8/55に各1枚、Z=−3〜0に配置。各板のM2×8をX=−5/12に2本、底から高さ8mmまでのφ7受けへねじ込む。下穴深さ6mm、ねじのねじ込み5mm、穴底余裕1mm。局所床は3.5mmへ増厚し、位置決めペグφ3×高さ1.2を各2本、ソケットφ3.3×深さ1.4へ挿す。ソケット上の肉厚は2.1mm。横方向片側0.15mm、深さ0.2mmの公称逃げで、左右の突合せ線そのものはX=3.5mmのまま。

ゴム足は計6個、φ8、床から突出6mm。外側4個は残存Wing穴と同軸、内側北寄り2個は接合板を避けてX=±24へ移した（Y=1.098076）。足座を局所高さ2.4mmへ増厚し、底のφ8.4×深さ0.4の位置決め凹みの上にも底厚2mmを残す。凹みに貼り、接合ねじ頭の下面Z=−4.6より床が1.4mm低くなる。足は購入品のゴム包絡として組立へ入れており、印刷ピースには含めない。

## 3D GH経路と高さ

Rev.3の北回り経路を採用する。17mm左右とも平面の滑らかな中心線は93.566882mm、元の折れ線94.097168mm＋30mmの割当は124.097168mm。GHは上面嵌合であるため、平面経路をそのままケーブル長にはしない。両端をZ=18.2mm、定常部をZ=23.2mmとし、両端に正確なR5の90°立体円弧を追加した。平面の各R5フィレットは元入力の中心・角度を使い、CADの円弧として再構築する。ケーブルはφ2の円断面を経路に沿って掃引した実体で、`harness.step` に出力する。

Mainの部品包絡はRev.4最終基板の配置を確認したA-2包絡を使う。L1のみ4×4予約を実図面の4.3×4.3に拡大した。高さの扱いは次の通り。

キーキャップ17mm角×高さ14mm、スイッチ15.8mm角、ケーブルφ2、曲げR5、Wing下面部品高さ3mmはStage 1の仮定を継承。底との下面部品の公称隙間は通常5mm、足座の局所増厚部では4.6mm。ハーネス幅φ2は14本束の供給仕様として確認済みではなく、実束径・端末高さ・可撓性が予約を超える場合は入力値を変更して再検証する。

## 200mm余長の収納

基本長はRev.3の約124mmを起点に立体曲げ分を加えた値とする。200mmを使う場合は、実経路から残る分のうち30mmを端末アプローチ／サービスの割当として確保し、残りを左右各1個のR5カプセル状サービスループへ束ねる。北側X=±18、Y=−44から南へ伸ばし、キー操作域へループを寄せない。寸法式は `直線部=(収納余長−2π×5)/2`、南北全長は直線部＋10、φ2包絡の幅12mm。

着脱式ラックは中央の基板がない首部X=1/Y=−14にφ4の柱を立て、Z=20.2〜22.2の横梁でケーブルを支える。柱の足元はφ4.4のソケットへ挿し、ナイロン結束材を梁の貫通スロットに通す。ラックは裏返して梁をベッドに置けば柱を垂直に印刷できる。上面開放なので結束を外してGHを上から脱着できる。

`storage-200mm.step` はこの長さを収納する包絡。通常経路と重ねた追加の2本のケーブルではなく、閉じたカプセルは容量とキー／部品間隔を確認するためのモデルである。30mm割当の引き回しと結束後の連続200mm実線形、ラッチ作業、実束の曲げは現物で確認する。SHの100mm候補はStage 1の中央開放首部へ通し、GH余長と一緒に締め付けない。

## 印刷方向と限界

トレー左右は底Z=0をベッドへ、接合板はZ=−3をベッドへ置く。縦壁・ボス・ペグ・リブは下から連続する。USB開口は上開きのままで屋根はない。南辺にも高いリップを追加していない。ラックは梁の上面Z=22.2をベッドに向けて反転し、柱を垂直に積層する。各ピースを個別に配置し、周囲5mmのブリムを含むXYと高さ250mmを検査する。

底側のゴム足凹みの天井は最大8.4mm、位置決めソケットの天井は3.3mm、接合下穴の天井は1.7mmの局所ブリッジになる。短いブリッジとしてサポートなしを想定するが、材料／冷却／スライサ条件を含む造形認定は実施していない。外壁・底厚・締結受けの実強度、ナイロンのクリープ、ねじの締付け、ゴム足の粘着、印刷収縮は実物評価に残す。製造・発注の承認を意味しない。

寸法・高さの仮定と余長の現物評価を上記の通り残し、Stage 2のデジタル成果物をブランチへコミットして停止する。pushはPMOが行う。
