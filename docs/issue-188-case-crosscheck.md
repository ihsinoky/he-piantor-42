**判定の理由**：J3 は支持ポリゴンから 4.5〜14.7mm 張り出し、ねじ固定点は近傍に無い。したがって J3 周辺の支持は「ケース側が基板下面・端部に接して荷重を受ける」方式にならざるを得ない。基板側にはそのための面（下面・北／東の部品なし帯）が残っているため、構造的に不可能とは言えない。一方、成立を言える根拠は無い：

- 挿抜力（実測待ち）、J3 北端張出しの剛性・ひずみ、上下拘束支持の必要荷重の入力が無い。
- GH ラッチの当たり面・移動量・指／工具の包絡が未取得（#163 の未成立点を継承）。
- #163 は「サービス矩形を縮めず維持」と記録したが、その後 #175 で確定した C26 は矩形に食い込んでいる。1210 の最大高さ（公表値未収集）と、ラッチ操作に C26 の空間が要るかは実物確認が要る。

「J3 を筐体が支える」要件（#150 に不在）に対する本基板の答えは、**基板改版なしで成立する余地はあるが、実物の挿抜・支持試験を経るまで OK とは言えない**。

## 5. D-017 の 100mm ハーネスと取り回し — 判定不能

**不足入力**：(a) M1 評価時の Main／Wing の組立位置・角度・Z（筐体 CAD または配置案）、(b) 100mm の測定基準（圧着接点間か被覆端か。#150 も実ハーネスで確認としている）、(c) 将来の逆ハの字の配置・傾斜角、(d) 実線材の曲げ条件と固定点。いずれもリポジトリ内に無く、組立配置を推測して OK／NG を出さない。

確認できた数値（設計値・仮定を明記）：

- D-017：公称 100mm、14 本、1:1。#150：空間経路 70mm 以下＋両端余長合計 30mm、曲げ半径 R≥5mm、通路幅 18mm 以上（これらは #150 の提案値でメーカー規格ではない）。
- J2 と J3 は Main の反対側にある（パッド列の Y 間隔 43mm）。Wing 側 J_WING は 16mm で (63,140)、17mm で (59.75,142.375) と各 Wing の南寄り。
- 楽観側の上界：2つの 90° 曲げ（半径 R）と直線だけで同一平面の2コネクタを結ぶ場合の中心間距離 D の上限は、経路 70mm なら R=3／5／8mm で 66.6／64.3／60.9mm、余長0で 100mm を丸ごと使うと 96.6／94.3／90.9mm。ケーブルは立ち上がり 7.3mm 以上（#160 の高さ感度では R=3〜8 で 10.68〜15.8mm）も要るため、実際の上限はこれより小さい。この値は合否ではなく、配置案が満たすべき最大の目安。
- M1 評価（Main 1枚＋Wing 1枚）で J2 と J3 のどちらを使うかは未定。J2 の pin7 は `WING_EN`、J3 の pin7 は `MUX_EN1` で、ネット名が異なる（機能同等かは本調査の範囲外）。
- 逆ハの字：ver.A 要件として記録（docs/lessons-learned）。角度・取付穴共通の前提のみで、傾斜角・Z は無い。

## 実物でしか決まらない事項（実測待ち）

- GH ラッチの当たり面・移動量・実挿抜力、全線把持との同時操作
- J3 張出し部の挿抜時ひずみと上下拘束支持の必要性
- 公差の積上げ（穴位置・外形・ボス・座金）、締付けトルクと POM のクリープ
- 全部品の実装後最大高さ、USB-C 開口面と USB プラグ外装の実寸
- ハーネスの実長・曲げ・固定点

## 対処案（判定とは分離。実施は PO 判断の別タスク）

1. **J3 支持の実物確認**：3D プリント治具に Rev.3 の実寸基板または外形モデルを載せ、下面リブ＋東側帯での支持を使った挿抜試験を発注前にできるか PO が判断する。成立しなければ基板改版（北側に支持用の穴など）が必要で、発注前に分かれば無駄な発注を避けられる。
2. **C26 の扱い**：実ハウジングを当てて C26 との干渉（ラッチ操作・指）を確認する。干渉するなら配置再検討（#175 の再資格が必要）。
3. **部品高さの収集**：BOM の全部品の公表最大高さを表にまとめる（J1、L1、C26〜C28、U6 を優先）。
4. **USB 開口**：J1 の実シェル座標とプラグ外装寸法で、ケース側トンネルの深さを確認する。
5. **ハーネス**：M1 評価の組立配置案（Main と Wing の相対位置）が出た時点で、上記の上界と照合する。
6. **右 Wing**：右形状の製造データが確定した時点で項目4を再実行する（`extract.py` は assert で不一致を検出）。
