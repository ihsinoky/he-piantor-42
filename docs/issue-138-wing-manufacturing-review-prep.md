## 4. 電流・許容電流の評価

### 4.1 データシートと負荷条件

部品実データはDRV5055A3QDBZR×21、TMUX1208×3。[TI DRV5055データシート](https://www.ti.com/lit/ds/symlink/drv5055.pdf)の取得版は **SBAS640C、2026年6月改訂**。p5 §5.5のICCは5.0V・B=0mTでtyp 3mA／max 5mA、3.3V・B=0mTでtyp 2mA／max 4mA。p4 §5.3は推奨電源範囲4.5–5.5Vまたは3–3.63V、推奨出力連続電流±1mA。基板のネット名はHALL_5Vなので5V側を主に評価し、3.3Vは比較だけとした。

**電流仕様の留保：** 同じRevCのp9 Fig5-13は代表供給電流が約5.3–6.5mAの曲線で、p5のmax 5mA（5V）と整合しない。改訂履歴には供給電流の変更が記載されている。旧版URL `sbas640b/sbas640b.pdf` も取得したが、応答は現行RevCと同じSHA256で、旧版の保証値は確認できなかった。表の値を採用した計算に加え、**10mA/センサを工学的な感度解析用包絡として計算**した。10mAを今回取得したRevCの保証最大値と称していない。温度・磁界・調達する部品の改訂との対応は発注前に確認が必要。

[TI TMUX1208データシート](https://www.ti.com/lit/ds/symlink/tmux1208.pdf)は **SCDS389C、2018年12月改訂**。p6の5V表はIDD max 2.7µA/個（−40～125°C）、p8の3.3V表はmax 1.5µA/個。供給電流の試験条件は制御入力0Vまたは5.5V。実際の3.3V制御・スイッチング時にその保証値をそのまま適用できるとは限らず、動的消費は残リスクにする。p6の制御入力リークはmax ±0.10µA/端子、p5のS/D連続電流の絶対最大は±30mAで、センサの推奨出力±1mAより大きい（絶対最大を通常動作目標にしない）。

PDF・抽出本文・URL・取得UTC・HTTP応答・SHA256は `E/sources/` と `reference-retrieval-records.json`。`drv5055-revb-url-returned-revc.*` は旧URLに対する現行版応答であり、旧版ではない。

### 4.2 外層1ozの電流容量

一般的な計算根拠として、[TI TIDA-01232設計ガイド](https://www.ti.com/lit/ug/tiducs7/tiducs7.pdf) p9式7と、[QorvoのPCB Trace Power Handling Calculator](https://www.qorvo.com/design-hub/design-tools/interactive/pcb-trace-power-handling-calculator)が記載する **IPC-2221外層の曲線近似**を使用した。QorvoはWeb閲覧で式と係数を確認したが、curl保存本文はブラウザ検証画面だったため根拠本文として使わない（`E/sources/qorvo-web-check.json`）。保存済みのTI設計ガイドPDFで式と係数を確認できる。IPC-2152を解いた結果とは表記しない。外層・銅厚35µm（1oz近似）・幅80µm・許容温度上昇10Kをこのレビューのスクリーニング条件とする。10Kは設計決定ではなく、評価用の明示的な基準である。

```text
A = (0.08 / 0.0254) × (0.035 / 0.0254) = 4.34001 mil²
I = 0.048 × ΔT^0.44 × A^0.725
I(ΔT=10K) = 0.383197 A
ΔT(I) = [I / (0.048 × A^0.725)]^(1/0.44)
```

| 定常電流 | 383.197mAとの容量比 | 推定自己温度上昇 |
| --- | ---: | ---: |
| 105.0081mA | 3.65倍 | 0.53K |
| 210.0081mA | 1.82倍 | 2.55K |
| 231.0081mA | **1.66倍** | **3.17K** |

**HALL_5V／GNDは、細い1線分にWing全体の231.0081mAが流れると仮定しても10K基準を通過。** 枝分かれへの均等配分、via本数による分流、周辺銅箔の放熱効果を合格理由にしていない。信号RAW／MUX_OUTはセンサ出力の推奨±1mAを上限とした場合、同じ断面の383mAより十分小さい。MUX制御4ネットは静的リークだけなら各3×0.10µA＝0.30µAである。MUXの信号経路に21個の供給電流が流れることはない。全60ネットの計算は [`E/electrical-evaluation.json`](../hardware/kicad/qualification/issue-138-wing-manufacturing-review-prep/electrical-evaluation.json)。

この値は条件付きの熱的スクリーニングであり、保証許容電流やIPC認証ではない。仕上り銅厚35µm未満、局部ネック、銅断面形状、周辺部品の発熱、筐体・周囲温度、隣接配線の同時加熱、viaめっき・はんだ接合、動的電流については別途確認が必要。部品の上限125°Cの周囲で自己発熱を上乗せしてよいという意味ではない。

### 4.3 抵抗・電圧降下の補助点検と電気的結論

幅80µm・銅厚35µmでは、銅の抵抗率を20°Cで1.7241×10⁻⁸Ωmと置くと**約6.16Ω/m**。同じ長さの100µm配線から抵抗は**25%増**になる。電流容量の合格だけでセンサ電圧やADC精度の合格とはしない。

補助的に、実配線・パッド・viaの位置を使う直流抵抗回路を作り、21個の負荷を各パッドに接続した。HALL_5VはJ_WING.1、GNDはJ_WINGの7端子を理想電源の基準とし、全ての定常負荷を同時に印加した。viaバレル20µm仮定、パッド内電流拡散と接触は集中定数近似。外部ケーブル／コネクタ／Main電源の抵抗は含めない。各負荷パッドへの接続とKCL、既知の直列・分岐回路で単位と電流の扱いを検証した。これは**電圧降下の規模を見る近似モデル**であり、完成銅箔の保証最悪値や有限要素解析ではない。

| 幅／温度／センサ電流条件 | 16mm 最大往復降下 | 17mm 最大往復降下 | J_WINGで4.75Vと仮定した最小局所電源（16 / 17） |
| --- | ---: | ---: | ---: |
| 0.08mm / 20°C / 表max 5mA | 0.234V | 0.240V | 4.516 / 4.510V |
| 0.08mm / 125°C / 表max 5mA | 0.331V | 0.339V | **4.419 / 4.411V** |
| 0.10mm / 20°C / 包絡11mA | 0.414V | 0.424V | 4.336 / 4.326V |
| 0.08mm / 20°C / 包絡11mA | **0.515V** | **0.528V** | **4.235 / 4.222V** |
| 0.08mm / 125°C / 包絡11mA | 0.728V | 0.745V | 4.022 / 4.005V |

4.75Vは5V−5%の**感度解析用仮定**であり、既存仕様として採用した値ではない。125°Cも抵抗温度依存の感度解析であり、その周囲温度での動作承認ではない。最も大きいセンサ降下は16mmのU_HB2、17mmのU_HB1。11mA包絡・20°C・最悪幅の場合、往復降下の内訳は16mmでHALL_5V 0.278V／GND 0.238V、17mmで0.304V／0.224V。入力が厳密に5.0Vでも局所電源は約4.485／4.472Vとなる。GNDの持ち上がりはアナログ測定にも影響しうる。出力負荷の同時性、実際のICC、供給端電圧、使用温度を確定して再評価する必要がある。

**結論：指定断面・負荷包絡での電流／発熱上の問題は見つからず、この理由だけの再配線は不要。一方、全使用条件での電気的無問題という判定は保留。** 電圧下限4.5Vを割りうる条件が補助計算にあるため、発注前にHALL_5V／GNDのDC給電・リターンとアナログ基準を確認する。これらの負荷／供給／温度条件を設計要求として維持するなら、**HALL_5V／GNDの幹線の拡幅・並列化・銅箔面等の補強と、それに伴う再配線が必要になる**。具体幅は許容電圧降下と配線可能性から決め、両ピッチでDRC・独立接続検査・幅監査を再度通す。今回、幅の採用決定やPCB変更は行わない。信号配線は定常電流を理由に太くする必要は見つからないが、ADC入力負荷・整定・クロストークの実機合格は別途必要。
