# Issue #150 — 筐体設計 Stage 1：機械要件と基板インタフェース提案

**M1 は「3Dプリントの開放トレイ＋交換式スイッチプレート＋高さ調整シム」を推奨する。Wing の外形・四隅穴は保持できる。一方、現行 Wing を Jade Pro の標準搭載基板として確定することはできない。** スイッチ位置決め穴がなく、センサは全21個が基板表面にある。メーカーの基板着座・下面センサ構成とは異なるためである。まず現行基板を加工しない持上げ式の評価治具として扱い、磁気曲線を確認する案とする。標準搭載を選ぶ場合は Wing 改版が必要となる。

[Issue #150](https://github.com/ihsinoky/he-piantor-42/issues/150) に対する**方式採用前の提案**。PO が方式を決める。Stage 2 の CAD、本製作、基板改版、発注・課金は行っていない。基板の電気的 DRC 合格を機械的適合の証明には用いない。

以下 E は [hardware/case/issue-150-stage1/](../hardware/case/issue-150-stage1/)。計算結果は [measurements.json](../hardware/case/issue-150-stage1/measurements.json)、Web 出典・取得状況は [sources/records.json](../hardware/case/issue-150-stage1/sources/records.json)。数値は mm。公表値、設計値、実測待ちを区別する。

各中心は板端から3。四穴のスパンは104×94／110.5×98.75。穴径は**ねじ呼び径ではない**。M2通しねじ＋絶縁スペーサを候補とし、頭・座金・接触ボス外径を最大φ4.5に制限する案。φ5内で半径0.25の余裕、板端までは0.75残る。市販品の実寸・公差は未選定なので、M2なら必ず収まるとは認定しない。四穴の位置誤差を吸収する浮動ナット／ケース側逃げを使い、基板穴の拡大、皿もみ、無理な四点締結は避ける。

**Wing 保持**：四隅で支え、PCBを平面に保つ。プレートは同じ剛性フレームへ別途固定し、打鍵荷重を小型センサやコネクタへ渡さない。1.2mm基板をねじで反らせて高さ調整しない。追加支点が必要なら下面の銅箔・ビア・はんだ形状を照合した絶縁パッドで支える。現在のkeepoutは4隅だけで、任意の中央ボスは承認していない。

**Main 保持**：新しい穴は開けず、下面・端部の実装を逃がした絶縁トレイと着脱クリップ／上からの枠押えを提案。USB挿抜荷重をトレイに逃がす。J1の固定脚・NPTHをケース固定に流用しない。基板端も配線があるため、支持面を製造外形と下面在庫で確認し、導電ねじや金属ばねで挟まない。クリップ実位置は Stage 2 の干渉確認で確定する。

### 全21中心の照合

各ピッチ全210ペアを、回転なしの同一高さの正方形包絡で検査した。親指も省略しない。ペアのX/Y中心差をdx/dy、幅をwとし、分離余裕を `max(|dx|,|dy|)-w` と定義する。これは円の中心距離ではない。両軸で重なるペアを列挙し、最小分離余裕を集計した。凸形状や高さの逃げを反映しない一次スクリーニングである。

| 包絡 | 16mm 最小余裕 | 17mm 最小余裕 | 判定 |
| --- | ---: | ---: | --- |
| Jade Pro 保守15.8角 | +0.200 | +1.200 | 理想中心・回転0では両方重複0。16は製作・遊び公差の余裕が乏しい |
| DSA 裾18.415角 | −2.415 | −1.415 | 両方不適合。包絡重複50／41ペア。丸隅による斜めペアの救済を見込んでも、同一列の隣接キーで干渉が残る |
| 狭幅キャップの設計上限15.0角 | +1.000 | +2.000 | 包絡重複0。**設計要求値**であり、購入可能な適合キャップを認定したものではない |

例：L_R0_C0→L_R1_C0 の中心差は(0,16)／(0,17)。幅18.415のキャップはそれぞれ2.415／1.415食い込む。高さ違いに頼って普通の1uを並べない。親指キャップも1キーごと15.0角以下の候補とし、1.25u以上・傾斜・軸オフセット・Choc用マウントを無条件採用しない。

狭幅共通キャップの受入れ案は、**実際の最大裾包絡≤15.0角、MX十字軸、全ストロークで下面がスイッチハウジングを避ける**こと。片キーの横遊び0.15、中心ずれ0.10を各側に割り当てると、16mmでも `16-15-2×(0.15+0.10)=0.50` の余裕が残る。15.0幅でスイッチ上面を覆えるか・軸の肉厚・保持力・底打ち時のリブ干渉は別途断面で確認する。狭いキャップを作れば必ず使えるとはしない。既製狭幅品の確定寸法資料は今回得ていないため、Stage 2 の候補選定／実測、または試作用専用キャップが必要。

スイッチ16mm側は中心ずれ±0.10ずつだけで `16-15.8-0.20=0`。さらに回転1°なら15.8角の投影幅は約16.073となる。したがって **16mmを量産適合と宣言しない**。プレートによる回転拘束と、実際の爪包絡・成形公差を確認する。17mmを先行して構造試験し、16mmは同等の試験片で別に判断する。両基板のセンサ中心を移して逃げる提案ではない。

## 4. スイッチプレートとキー位置穴

プレートを設ける。HEスイッチには通常接点のはんだ固定がなく、現行PCBには位置決め穴もないため、キー位置・回転・抜け止めをプレート／補助ガイドが担う。打鍵で磁石距離が揺れない剛性が必要で、柔らかいガスケットや基板全体を曲げる構造は初回の距離評価に採用しない。

- 開口は回転を拘束する**正方形**を第一案とする。検討開始寸法は **14.15±0.05角、厚さ1.50±0.05**。胴体最大14.05に対して穴最小14.10なので全幅0.05の挿入余裕。メーカー保証ではなく、抜け止め爪が掛かるかを検査する試験片の開始値である。
- 14.10／14.15／14.20角の試験片で挿抜・爪係合・横遊び・回転を確認してから確定する。レーザーのkerf／FDM収縮／CNC工具Rを製法ごとに補正。角Rは胴体と爪に干渉させず、必要なら局所逃げを使う。スイッチを開ける大型切欠きを狭ピッチに足さない。
- 開口14.15で、同列の最小ウェブ公称は16側1.85／17側2.85。穴寸法最大・中心誤差を含め再計算する。FDMの薄いウェブ単体には頼らず、1.5mmの切抜き樹脂板またはGFRP板を交換部品とする案が第一候補。強磁性の鋼板は磁気系を変えるため避ける。金属案は非磁性材でも磁気・ノイズ実測を行う。
- キー中心は E/keys-16mm.csv／keys-17mm.csv。センサ中心を基準とし、列ずれ・親指を保持。スイッチ磁石軸とステム中心の一致・方向は図面と実測で照合し、センサ実装の位置ずれを含める。#149のピッチ角のシルク枠を実スイッチ外形や切削線に転用しない。
- プレートとPCBを四隅の共通フレームで位置合わせし、プレート側のストッパで回転拘束する。開口だけで横公差を満たせなければ非磁性の追加ガイドを検討し、16mmの余裕を再判定する。爪が掛からない場合は交換式リテーナが必要で、摩擦嵌合だけを恒久保持にしない。

## 5. 磁石〜センサの距離チェーンと公差

### 座標と式

PCB表面を `z=0`、スイッチ方向を正とする。`t`=PCB厚、`H`=PCB表面からプレート上のスイッチ支持面まで、`b`=その支持面からスイッチ基板着座面までの深さ、`m(q)`=着座面から磁石の評価点までの符号付き高さ、`q`=押下量。センサ実装の追加浮き量を `j`、リード着座面からHall素子までを `h` とする。

```text
キーキャップ                  全ストローク中の裾・リブ包絡を確認
ステム / 磁石                 z_m = H - b + m(q)
プレート支持面                z = H
スイッチ基板着座面            z = H - b
                 空間         現行基板を使う治具では持上げる
Hall素子（現行：表面）        z_s = j + h
PCB表面                       z = 0
PCB下面                       z = -t
下面Hall素子（改版候補）      z_s = -t - j - h
```

現行表面センサでは `g_top(q)=H-b+m(q)-j-h`。下面センサなら `g_bottom(q)=H-b+m(q)+t+j+h`。このgは軸方向差であり、横ずれρがあれば磁場分布も変わる。単純に磁束を距離の一次式へ変換しない。

[TI DRV5055 Rev.C](https://www.ti.com/lit/ds/symlink/drv5055.pdf) §6.3.8（PDF14頁）は SOT-23 の素子中心XY±0.05、着座面からの高さ `h=0.650±0.080` を示す。DBZ図の最大全高は1.12。E/sources/ti-hall-location-page14.png を確認した。部品外形の中心とHall素子と磁石軸を区別する。

**PCB1.2という一致だけでは、120／700 Gの条件を再現できない。** 現行センサ面とメーカーの下面断面は異なる。`m(0)`、磁石端面／中心のどちらが磁束の基準か、メーカー試験に使ったHallの素子高さは公開図だけでは確定できない。従って絶対gの公称値と磁束合格範囲は未確定。PCB1.2をプレート1.2と読み替えない。

### 公差配分案（実測・部品保証ではない）

| 項目 | 片側公差の初期予算 | 吸収／管理方法 |
| --- | ---: | --- |
| PCB表面→プレート支持面H | ±0.15 | シム選択・実測。内訳目安：スペーサ±0.05、プレート厚±0.05、着座／組立±0.05。厚さをHと二重加算しない |
| スイッチ支持面→着座面b | ±0.05 | 図の5.00寸法を候補。厳密な支持面の対応を確認するまで仮置き |
| Hall素子高さh | ±0.08 | TI公表値 |
| はんだによる追加浮きj | ±0.05 | 設計予算。PCBA実測で確認、必要なら予算変更 |
| 打鍵時相対たわみ | ±0.10 | 暫定構造目標。四隅支持・補強で実測 |
| PCB厚t（下面型だけ加算） | ±0.12 | 1.2の±10%という**仮予算**。発注仕様の保証値とはしない |
| 磁石位置m(q)・底打ちの個体差 | 未確定 | スイッチ実測・メーカー確認。ストローク公差±0.2も底側に効く。未知を0としない |

表面型の既知部分はworst-case **±0.43**、下面型は **±0.55**。独立正規分布を仮定したRSSで小さく見せない。さらに磁石位置と押下量の不確かさが加わる。したがってこれらは総合距離公差の保証値ではなく、電気的評価へ渡す上限候補である。

XYはプレート中心±0.10、PCBとプレートの位置合わせ±0.10、センサ実装±0.10、Hall素子±0.05で、各軸worst-case±0.35の初期予算（半径なら約0.495）。磁石偏心・軸遊びは未加算。これで適正磁束になるとは未確認。16mmの**スイッチ相互干渉**の予算はこの磁気軸合わせ予算とは別に管理する。

### 現行PCBを無加工で使う持上げ式治具

PCB表面の上にセンサがあり、位置決め脚の穴もないので、スイッチ全体を浮かせる。初期案は `H=10.00±0.15`、`b≈5.00±0.05`、下面への突出最大2.80、センサ最大1.12＋追加浮き0.10を避ける設計とする。全スイッチ投影に対して安全側に一律の下端包絡を取ると、

`H_min必要 = 5.05 + 2.80 + 1.12 + 0.10 + 安全隙間0.30 = 9.37`

Hを10にすると最小隙間は `9.85-5.05-2.80-1.12-0.10=0.78`。これは**センサとの固体干渉だけの検討値**。隣の0603・mux・爪・底蓋など全体積もStage 2で確認する。支持面の解釈が違えば再計算する。磁石距離はメーカーの標準着座から変わるため、0.86V等の既存予測を保証しない。シムを減らして感度を上げる場合も9.37の干渉条件を下回らない。磁束が不足するならこの治具案は不採用とし、脚切断やPCBAへの追い穴を即席の解決にしない。

## 7. コネクタ／ケーブルの取り回し

[JST GH公式資料](https://www.jst-mfg.com/product/pdf/eng/eGH.pdf) PDF2–3頁をWebで確認した。BM14Bは上挿し型で、本体幅20.75、奥行4.25、高さ4.05、嵌合時高さ5.7。GHR-14V-S本体幅18.75。適用電線外径は0.76–1.0。資料の直curlは403だったため、ローカルPDFを取得したとは記録せず、Web読取と既存G0Bの一致で扱う。

| 対象 | 現行XY | 予約領域・アクセス |
| --- | --- | --- |
| Wing16 J_WING | 63,140 | definitionの予約矩形をKiCad変換するとX50–76／Y139–147（26×8） |
| Wing17 J_WING | 59.75,142.375 | X46.75–72.75／Y141.375–149.375（26×8） |
| Main J2 | 110,116 | 南側に独立したサービス空間。TP1〜4の列とフックが干渉しないこと |
| Main J1 USB-C | 85,81 | 北側外周に窓を設ける。コネクタ中心＝USB開口面ではないので、実シェルとケーブル成形部で位置・寸法を決める |

26×8は**平面予約**であり、5.7mmの嵌合高さやラッチ解除・上向き抜取りまで保証しない。両Wingの下側サービス帯をプレートのキー部とは分離し、GH上は着脱蓋／開放として、初期案ではPCB表面から12mm以上を電線と曲げの空間に予約する。プラグを上へ抜けるアクセスは蓋を外した状態で確保する。壁や蓋を嵌合体の押えとして使わない。

MainポッドをWingのサービス帯近傍に置き、GH嵌合位置間の実配線経路を**100mm以内**に納める。設計目安は、配線の空間経路70mm以下＋両端で合計30mmの余長。長さ100mmの測定端が圧着接点か自由線長かは実ハーネスで確認する。14本を平たく並べるなら電線だけで最大14mm、結束・遊びを含め通路幅18mm以上を提案。26mmの予約幅内に通せるが、ボス・ラッチとの重なりを実物で確認する。

曲げ半径は初期目標 **R≥5mm**（メーカーの最小曲げ規格ではない）。ケース側クランプは絶縁被覆を軽く保持し、接点から引張荷重を離す。はんだランドや細線へケースの荷重をかけない。電線をキー／磁石の上下動域、ねじ先、プレート端、PCB端に通さない。GHに手を掛けてロック解除でき、ケーブルを引張らず抜ける構造とする。

USBは選んだケーブルの成形部・曲げを含む包絡に片側0.5を足した窓を決める。一般的なUSB-Cという名称だけで開口を固定しない。MainはSWDIO、SWCLK、RUN、QSPI_SS_FLASHのTP列（XY=88/91/94/97,118）へ上からアクセスできる開放蓋とする。現行MainにはJITX旧板のSW_BOOT／SW_RUNの物理ボタンを前提にした窓を設けない。Wingの上下サービス帯TP、raw Hall／MUX測定もキー部と独立して接触可能にする。

## 8. 筐体構成比較とM1推奨

価格・納期の見積りや注文操作はしていない。相対的な製作特性による比較である。

| 方式 | 利点 | 制約／この構成での懸念 | M1評価 |
| --- | --- | --- | --- |
| FDM等3Dプリント単体（プレート一体） | 安価な形状修正、ポッド・配線路を一体化しやすい | 14mm穴の収縮、爪の板厚、16mmの細いウェブ、反り・クリープがHとXYに直結 | トレイ向き。精密なプレート一体化は第二案 |
| **プリントトレイ＋別体薄板プレート＋シム** | PCB保持とキー保持を分離、両ピッチを交換でき、Hを測って調整できる | 複数部品の基準合わせ、薄板材と加工精度、非磁性締結・たわみ確認が必要 | **第一推奨**。17mm先行、16mmも別プレートで評価 |
| 積層アクリル | 平面加工で形状をレビューしやすく、層の交換が容易 | 標準3mm板はスイッチ爪に不適合の可能性。1.5mm層の割れ、16mmウェブ、層公差の積み上げ、ねじ締め割れ | 底板／側壁には可。穴・クリップを実証するまでプレートは条件付き |
| CNCアルミ／樹脂 | 基準面・支持剛性・繰返し精度を得やすい | 採用前の高さ変更が高コスト、内角R・工具制約、金属の絶縁と磁気評価 | 磁気と方式が確定した後の候補 |

第一案は、左右を含む製品用の薄い閉鎖ケースを先に作るためではなく、**現行M1を支持し、距離・ピッチ・キャップを比較するための開放治具**とする。大きな金属天板や鋼ねじを磁石の近傍に置かない。ねじ材は実物の磁性を確認し、初期は樹脂などの非磁性材を優先する。持上げ式で磁気が成立しなければ、方式の長所とは切り離してWing改版へ戻す。

## 10. PO判断とStage 2への引継ぎ

本Stage 1で提案する判断は、**外形・四隅穴・Mainの穴なし支持・GH位置を保持し、交換式プレート付き開放治具をM1候補とする**こと。機械インタフェース全体を「凍結済み」に更新しない。特に標準着座のスイッチを要求するなら、現行Wingのまま発注確定する判断は保留する。

Stage 2の実行開始条件はPOによる方式採用。以下を設計・受入れ条件として渡す（このIssueでの試作実施ではない）。

1. **実部品の寸法確認**：Jade Proの型番、爪、位置決め脚、支持面b、磁石軸／高さm、全押下時の底面、キャップのMX嵌合・幅・裾・Cを測る。図面との対応が不明なら部品メーカー資料で確認。
2. **試験片→位置保持**：14.10／14.15／14.20穴と板厚1.5候補を確認。両ピッチで21キー全域の隣接干渉、回転、キャップの同時押下、抜け止め・交換工具を検査。16mm側の公差余裕が成立しなければ不採用または部品条件を見直す。
3. **距離と磁気の成立**：PCB・プレートの9点以上でHを測定。隅／中央／親指で静荷重と打鍵時の相対変位を測り暫定0.10以下を確認。上下端、全ストローク、隣接同時押下、温度・繰返しで既存評価計画のクリップ余裕／ノイズ／単調性／再現性を測る。許容磁気曲線が未定の項目はPO／電気担当で受入れ値を決める。公称120／700Gへ無理に一致させない。
4. **筐体・ハーネス実装**：全部品体積と下面はんだ、ボス、USB挿抜、GHラッチ、R5案、100mmハーネス、TPアクセスを3D干渉と実組立で確認。製法の収縮／切削／穴位置公差・外装のたわみを吸収。
5. **基板凍結の再判定**：持上げ治具が成立すれば現行M1の機械支持条件を記録して採用可否を判断。成立しない、または標準着座が必要なら、両ピッチで位置決め穴・センサ面／位置・必要な配線改版を別Issueで設計し、再DRC／CAM／PCBAと磁気評価を通す。Stage 1 の文書受入れを製造GOとしない。
