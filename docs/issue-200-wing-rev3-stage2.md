# Issue #200 Wing Rev.3 — Stage 2（レイアウト・再適格化・製造データ）

Stage 1b の確定形状（`hardware/case/issue-200-stage1/geometry.json`）に基づき、16/17mm × 左右の4基板を個別生成し、配線・再適格化・電源再計算・ケーブル/Main 干渉確認・製造データ・ケース用 CSV を揃えた。発注・見積、ケースのモデリング（#198）は対象外。D-034 は草案で、**ハーネス長の判断は未決**。

成果物と再現手順は `hardware/kicad/qualification/issue-200-wing-rev3/README.md`。基板は `wing-rev3-{16,17}mm-{left,right}/main.kicad_pcb`、受入れは各 `qualification.json`（PCB の SHA-256 を束縛）。

## 1. 基板・配線の方針と根拠

- 外形・GH 位置は geometry.json のまま。Rev.2 の各基板（右は鏡像でなく個別生成）からキー／センサー／Hall・ローカルコンデンサ／ロケータ穴／ピン対応を保持し、北のサービス部品だけを移した（`build.py`）。右基板は部品の実回転で作り、パッド・銅の鏡像化はしていない。
- トリム域内の MUX×3・コンデンサ・テストポイント15点は北サービス域へ再配置した。テストポイントは上面に残し、実装後もアクセス可能（`verify-mechanical.py` の垂直 1.2mm プローブ確認）。
- 取り付け穴は H1 候補を採用（左 H1 (3,−5)/(4,−6)mm、右 H3 は X 負側。16/17mm）。座標変更なし。スイッチ領域との間隔は 0.70mm（16mm-left）〜1.20mm（17mm-right）。
- D-021 を維持：2層、1.2mm、信号 ≥0.10mm、電源/GND ≥0.30mm、クリアランス ≥0.10mm、via 0.60/0.30。南 2mm 帯は前面 HALL_5V・背面 GND の面で電源/GND 帯とし、信号配線・via の侵入は全版 0。
- 17mm-right は回転した MUX のファンアウトが最難所で、格子 A* の迂回を使った。最後の残件（独立ゲートの track_dangling）は、行き止まりの階段状ひげ（H_C4_RAW と MUX_OUT_A）を、実接点より先だけ切り戻して解消した。切り戻しは native DRC の未接続 0 を確認しながら行い、`qualify.py`（cleanup → via-margin → 独立ゲート）を通した。

## 3. 電源（Rev.3 の基板抵抗に置換）

`extract-resistance.py` が各最終基板の充填銅を2層シート＋via バレルとしてモデル化し、127mA/Wing の分布負荷を粗/細メッシュ・公称/80%幅で解く。旧 #141 由来の Wing 内部降下（17mm で 0.1477V）を、抽出したターミナル降下に置き換えた（`power-summary.py`。古い基板ハッシュは拒否する）。Main Rev.4 #196 の共通/分岐抵抗はそのまま。

Wing 内の最遠端子の降下（往復、20°C、公称幅）：

| 基板 | 最遠端子 | 降下 (mV) | 実効ループ抵抗 (mΩ) |
| --- | --- | --- | --- |
| 16mm-left | U_HB1 | 1.40 | 11.05 |
| 16mm-right | U_HC1 | 0.94 | 7.42 |
| 17mm-left | U_HC1 | 1.18 | 9.29 |
| 17mm-right | U_HC1 | 1.94 | 15.31 |

最悪条件（Main の 125°C・幅80%、127mA/Wing、2 Wing 同時、レール 5.2V±2% と未モデル分 0.05V、U5 Ron 0.25Ω、GH 接触 0.05Ω/箇所×2、帰路6本）でのシステム最遠点電圧。最悪基板は 17mm-right（Main 分岐 J3、最遠 U_HC1）：

| ハーネス長 | ハーネス降下 (V) | Wing 降下 (V) | 最遠点電圧 (V) | 4.60V に対する余裕 (V) |
| --- | --- | --- | --- | --- |
| 124.097mm（新経路ベース） | 0.0204 | 0.0028 | **4.9463** | +0.346 |
| 200mm（採用済み） | 0.0238 | 0.0028 | **4.9429** | +0.343 |

**200mm でも 4.60V を割らない**（`adopted_200mm_below_4p60 = false`）。ハーネス長を変えても余裕は 3mV 強しか動かず、電圧面ではハーネス長を決める根拠にならない。限界：設計モデルであり実測保証ではない。ピン接触・ハーネス抵抗・銅の最小厚/エッチングは実物受入れが必要。125°C は感度解析で、GH のカタログ上限 105°C を超える（組立の動作温度として認定するものではない）。上流（UDB/SH/USB）が #196 の前提を満たすことを前提とする。解析 FEM の自己検証は `fem-selfcheck.json`（解析解との相対誤差 ~1e-15）。

## 4. ケーブルと Main の干渉

`harness-clearance.py` が Main Rev.4 の上面フットプリント59点を調べた。経路は新ハーネス経路（折れ線 93.567mm、R5 の Z 曲げ2回込み 99.275mm、必要導体長 124.097mm、曲げ後の余裕 24.82mm）。XY 経路の変更は全版で不要。

- 経路下に入る Main 部品は GH コネクタ1個のみ：左 Wing は J2、右 Wing は J3（BM14B-GHS-TBT）。嵌合基準高さ 7.3mm、予約高さ 8.0mm（上面 z=19.2mm）。ケーブル水平部の中心 z=24.2mm。意図したプラグ/ワイヤ接続端なので端点の離隔はゼロで、以降は鉛直/R5 で立ち上がる。
- ケーブル下端と予約上面との隙間：束 φ2 で 4.0mm、φ5 で 2.5mm（下端 z=21.7mm）。
- その他の Main 上面部品は経路下になく、平面で全て離隔している。φ5 掃引の最小平面ギャップは左版で U4 まで 0.05mm、右版で C27 まで 0.771mm（φ2 では 1.55／2.271mm）。これらは経路の外側にあり、ケーブル下端 z≥21.7mm に対し部品高さは十分低いので鉛直干渉はない。ただし左版の φ5 は平面で 0.05mm と近く、ケース/ハーネス設計（#198）で U4 周りの実物確認をする。
- キー包絡（42キー）との交差は全版 0。ギャップは 16mm 版で 7.89（φ2）/6.39mm（φ5）、17mm 版で 9.01/7.51mm。UDB との間隔は φ2 で 3.0mm、φ5 で 1.5mm。
- ケーブル上端 z=25.2（φ2）/26.7mm（φ5）に対し、蓋/リテナーの内側は 0.5mm 余裕で 25.7／27.2mm 以上を要する。
- 限界：高さは JST eGH 資料の上面入力の参考値（認証済み許容値ではない）。14本、各被覆外径 ≤1mm を φ5 以内に収める設計予約で、φ2 は Stage 1 のスクリーニングに過ぎず完成ハーネスの仕様にしてはならない。200mm の余長の収納、ストレインリリーフ、線順、実曲げ半径は物理確認が要る。

## 5. 製造データ

Issue #158 と同じ左右一体パネルをピッチごとに生成（`panel-16mm`、`panel-17mm`）。両面実装のため **Standard PCBA** が必要（実装は下面84点・上面14点）。各パネルに CAD、Gerber（銅・マスク・ペースト・シルク・外形）、PTH/NPTH ドリル、`fabrication.zip`、BOM、CPL（絶対 X、Y 反転、上面視 CCW、面を明記）、`pin1.csv`、上下面組立 SVG、パネル形状、フル DRC、via–パッド全数監査を含む。単板の CAM も出力した。全銅箔→タブ距離は 2mm 以上、タブは無銅。

検証：`verify-panel.py`、`verify-cam.py`（ドリル・外形セグメント682・ハッシュ・CPL/BOM の照合）が全て合格。`verify-cam.py` は、ドリル座標の期待値が 0.0005mm 丁度の位置で四捨五入が割れて偽の不一致になっていたため、整数 nm の半切り上げに直し、パネル検索を `panel-*mm` に限定した（検査の厳しさは変えていない）。

ケース用 CSV は `hardware/case/issue-200-rev3/`（キー、ロケータ/取り付け穴、段差・肩を含む外形。4版）。#198 の入力で、ケースそのものは生成していない。

## 6. 未決・物理受入れ

- **ハーネス長（124.097mm / 200mm）は未決**。D-033 は 200mm。電圧は両長で十分（3 節）。決定は PMO。
- 分離/DFM、ロケータ NPTH 1.70±0.05mm の仕上がり、機械ごとの CPL 回転（`pin1.csv` で確認）、磁気応答・ノイズ・組立後の電源の実測。
- ハーネスの実外径・曲げ・ストレインリリーフ・200mm 余長収納、U4 周り（左 φ5 の平面 0.05mm）の実物確認。
- 発注・見積は対象外。Rev.3 の価格は再見積すること。

## 7. 作業メモ（再現性）
