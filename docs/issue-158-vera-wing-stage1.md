## 2. 標準着座のキー単位要件

### 2.1 位置決め穴と座標規則

[Gateron公式仕様書 SPEC-KS-20T-041 v1、2024-08-19](https://www.gateron.com/u_file/2505/21/file/GateronMagneticJadeProSwitchKS-20TF10B045NW-Y106PRO1.pdf) のPDF7頁を再確認した。対象はfull-height Jade Pro `KS-20TF10B045NW-Y106`。図のφ1.70±0.05の位置決め穴2個、PCB1.20、下面Hall構成を要求とする。推奨PCB図の1.27方眼は、穴が横方向に8区間離れ、キー軸を中央と読むと **穴中心間10.16、局所座標(-5.08,0)/(+5.08,0)** になる。これは**方眼読取による配置仮説**であり、座標公差の明記された穴表ではない。図の上面／下面視、磁石軸との一致、方眼解釈と脚位置公差をメーカーまたは実物で確認するまで製造座標へ凍結しない。[読取画像](../hardware/kicad/qualification/issue-158-vera-wing-stage1/sources/gateron-drawing-page7.png) とPDF hashを保存した。

キー中心K、実物で確認したローカル向きθに対して、`P± = K + R(θ)·(±5.08,0)` を基本規則とする。現行21中心は回転0だが、親指も含めスイッチ向きとRGB開口方向を別途定義する。図の0.8角3パッドはメーカーが想定したHallの例で、現行DRV5055のランドとしてコピーしない。中央穴・通常MXの接点穴・RGB穴を追加必須と解釈しない。

穴は無めっきNPTHとし、銅・via・zone・pasteを全層で逃がす。**21キー×2=42穴/Wing、左右では84穴**。ケース用4穴/Wingとは別物で、左右の総NPTH数は位置決め84＋取付8＝92（パネルタブ・工具穴を除く）。φ1.70±0.05が完成穴として必要なことを工程に明記し、製造者の一般NPTH公差で自動充足するとしない。脚径最大・テーパー・位置公差と穴最小1.65を照合し、無理な圧入や脚切断を設計解としない。

### 2.2 下面Hallと検出距離

上面をz=0、スイッチ方向を+z、PCB厚をtとする。#150と同じ記号で、HはPCB上面→プレート支持面、bはその面→スイッチPCB着座面、m(q)は着座面→磁石評価点の符号付き高さ、jは実装浮き、hはリード着座面→Hall素子高さ。

```text
プレート支持面       z = H
スイッチ着座面       z = H-b = e（標準着座の理想はe=0）
磁石評価点           z_m = e+m(q)
PCB上面              z = 0
PCB下面              z = -t
下面Hall素子         z_s = -t-j-h
軸方向差             g(q) = e+m(q)+t+j+h
```

標準着座ではHとbを独立に積み上げて浮かせず、プレートとPCBを共通フレームで整合させ、着座浮きeを管理する。PCB1.2と、#150で開始案としたプレート厚1.5は別の値である。プレート開口14.15±0.05角／厚さ1.50±0.05はメーカー保証値ではなく、実物の爪・支持面で確認する試験片候補にとどめる。

[TI DRV5055 Rev.C §6.3.8／DBZパッケージ](https://www.ti.com/lit/ds/symlink/drv5055.pdf) の素子高さはh=0.650±0.080、XY素子位置±0.05、パッケージ最大全高1.12。t=1.2なら `g(q)=e+m(q)+1.85+j` が公称式となる。m(q)、実際のはんだ高さ、メーカー磁束試験のHall位置は未確定なので**絶対検出距離は算出不能**。メーカーの120±8Gは0.3押下、700±30Gは500gf時の条件で、無押下／通常底打ちの保証値に置き換えない。全ストローク3.5±0.2、N極がPCB側という条件を維持する。

初期予算はt±0.12（仮の10%）、h±0.08（TI）、j±0.05（設計配分）、着座浮きの影響≤0.10、動的相対たわみ≤0.10を置く。既知項の変動予算を保守的に加算すると0.45相当だが、磁石個体差・押下量差・脚の拘束は未加算で総合保証ではない。#150の持上げ型±0.55を標準着座の保証公差として継承しない。XYも実装±0.10＋素子±0.05を出発点とし、穴／脚の遊び・プレート整合・磁石偏心を別に加える。脚の公差が未取得なので磁気軸ずれの総量は保留する。

DRV5055は評価継続候補で、最終センサー選定は未完了。B.Cu化ではパッケージの検出方向とpin配列を実データシート・実物で確認し、磁界に対する出力符号、オフセット、Main分圧後のADC飽和余裕を再評価する。0.86V等の現行予測は継承しない。素子中心を磁石軸へ合わせ、ランド原点や外形中心だけを合わせて済ませない。

## 3. 左右展開とGH14互換

左右を同じ表面視座標（中心原点、+X右、+Y上）で扱い、キー中心は `K_R=(-x_L,y_L)`。右キーIDはL→Rへ対応させる。列ずれと3親指を含む21中心を鏡映し、基板裏返しや180°回転で代用しない。右にも「上にスイッチ、下にHall」を維持する。

**鏡映するのはキー配置であり、極性部品のランド・pin番号を絵として反転しない。** スイッチは実在する同一部品の平面回転で置く。Hall、MUX、GHも実在フットプリントを再配置し、B.Cuへの面変更と回転でネット対応を照合する。右のGH位置は機械的な鏡像を候補とし、ケーブルアクセスが成立する向きを選ぶ。pin1位置は再表示・検査し、左右同じpin契約を優先する。

| GH pin | 左右共通ネット | 役割 |
| ---: | --- | --- |
| 1 | HALL_5V | Mainからの共通switched供給 |
| 2,4,8,10,12,14 | GND | 6本個別帰線、全て同一GND。予備信号へ転用しない |
| 3,5,6 | MUX_A0,A1,A2 | 共有3.3Vアドレス |
| 7 | WING_EN | 左右のMainポートごとに独立EN |
| 9,11,13 | MUX_OUT_A,B,C | rawアナログ。Mainの分圧・フィルタへ |

GHはD-017と同じBM14B-GHS-TBT(LF)(SN)、GHR-14V-S、SSHL-002T-P0.2を前提とする。左右とも21Hall／3TMUX、3群×7アドレスを維持し、同じ論理キーの鏡像に同じ(group,address)を割り当て、bankで左右を区別する。S8はNCのまま。現行Mainは1ポートであり、同時42キーには#157の2ポート・独立EN実装が必要。外部Y分岐や両EN同時highは採用しない。

#157案に合わせ、Mainの各ENに外付けPD、共通HALL給電default-off、両EN off→アドレス変更→片EN on→実測settling→取得を要件化する。Hall42個は常時給電されるのでEN交互でも電源負荷は半減しない。各100mm・14本1:1を基準とし、製品のケーブル長変更時は電源・ノイズ・settlingを再評価する。同型GHは左右入替えを機械的には防げないため、L/R表示・固定経路・導通検査・左右キー試験を用いる。ID線の追加はしない。

## 4. 外形・取付穴の保持可能性

現在のKiCad上面視・X右/Y下、mmで比較する。各取付穴はφ2.2 NPTH、全銅層に公称φ5予約を維持する案。穴番号の並びではなく座標で契約する。

| ピッチ | 外形X／Y | 幅×奥行 | 4穴X集合×Y集合 |
| --- | --- | --- | --- |
| 16 | 45–155／50–150 | 110×100 | {48,152}×{53,147} |
| 17 | 41.75–158.25／47.625–152.375 | 116.5×104.75 | {44.75,155.25}×{50.625,149.375} |

E/analyze.pyは#141 native PCBとdefinitionを照合し、±5.08穴仮説を全21キーへ適用して以下を計算した。穴径は最大1.75、取付予約円半径2.5、銅から穴縁への逃げは**仮の0.25**。穴位置誤差や切削誤差は未加算。

| 仮配置による一次検査 | 16 | 17 |
| --- | ---: | ---: |
| 位置決め穴縁→外形の最小余裕 | 5.045 | 5.545 |
| 位置決め穴縁→φ5取付予約円の最小余裕 | 8.975 | 9.826 |
| 位置決め穴相互の最小残り材幅 | 4.090 | 5.090 |
| 既存segment/viaと逃げが衝突する穴 | 33/42 | 31/42 |
| 衝突した異なるsegment／via数 | 68／8 | 55／6 |

この仮説では穴追加だけを理由とする外形拡大・キー中心移動・取付穴移動は不要と判断できる。一方、既存銅配線への追い穴は不可。集計はsegment/viaのみで、pad・zone・部品courtyard・3Dは未検査なので衝突総数の下限側の証拠である。公差と脚の実寸、全面の配置／配線／製造確認後に保持可否を確定する。右の鏡像でも理想幾何距離は同じだが、再配置した部品・GH・配線の合格は別に取る。

16/17の外形は異なるので、ピッチ未決のまま一つの製品外形を凍結しない。現行の四隅3mm内側という関係を候補契約とし、選定ピッチ側の外形・穴集合を採用する。穴追加でキャップ干渉は改善しない。#150ではスイッチ保守15.8角の理想隙間は16で0.2、17で1.2、比較用DSA18.415角は両方不適合だった。狭幅キャップ・成形公差・回転・工具アクセスの実測が残る。16.5評価はD-017に残っており、今回16/17の検査から自動的に認定しない。

## 5. 左右一体パネルと自宅分離

**第一案は、左右を同じ表面向きで横並びにし、長辺の間を約2mmルータ溝＋無銅のmouse-biteタブで接続する方式。** 電気的には独立した2枚で、信号・電源・GND・plane・試験配線を接合部や外周レールへ一切渡さない。自宅で分離後、GHハーネスでMainへつなぐ。左右を機能的に一体化してから銅線ごと折る方式ではない。

```text
       搬送・支持用外周レール（必要寸法は製造者確認）
  ┌────────────────────────────────┐
  │  左21キー 上面視   ║ 右21キー 上面視 │
  │                   T                │
  │  Hallは下面       T  Hallは下面    │
  │                   T                │
  │  上面GH/MUX帯     ║ 上面GH/MUX帯   │
  └────────────────────────────────┘
  ║ ルータ溝、T 無銅タブの候補（実座標は未設計）
```

接合部は中央辺の30/50/70%付近を**探索開始領域**とし、取付穴・親指・GH・MUX・下面Cから離して3箇所程度を候補にする。位置を凍結せず、必要なら中央の捨て帯や外周レールにも支持タブを増やす。長い1.2mm板の搬送／2回リフローを支えられることと、手元で工具が入ることを両立させる。

設計開始例はタブ幅5、φ0.6の5穴を0.9中心間隔（孔列全幅4.2）とする。これは工具で切れるかを試す**未承認の試験寸法**で、必要強度・残肉・孔列位置を製造者と実装後の試験片で決める。[JLCPCBのmouse-bite案内](https://jlcpcb.com/blog/pcb-design-efficiency-mouse-bites) は5–8穴・φ0.60を推奨しているが、今回のタブを認定するものではない。全銅層・部品・via・TPは、孔列／切断工具の掃引包絡から暫定2mm以上退避し、剥離・研磨・切断位置誤差を含めて増やす。普通の板端clearance0.10をタブの切断損傷余裕として使わない。

取付穴のある角付近にはタブを置かず、ボス・ねじ頭・GHアクセスを避ける。分離後のバリが矩形外形から出る可能性があるため、孔列は捨て側へ寄せ、残りを工具で仕上げて外形公差内へ収める案を優先する。食込みノッチで逃がす代案は実質的な外形変更なので別途明示する。位置決め穴と取付穴を折り始点として使わない。

自宅分離は、電源・ハーネス・スイッチを外し、下面Hallを押さない支持治具でタブ両側を保持し、フラッシュカッター／タブ切断工具で一本ずつ切る。基板全体をねじって折らない。切屑を除去してバリ・銅露出・クラック・下面部品を拡大観察し、電源短絡・全14pin導通・全42キーとゼロ点を再確認する。これは後続受入れ手順であり、今回分離実験は行っていない。

| 代案 | 評価 |
| --- | --- |
| 全長V-cut | 直線矩形には使えるが、長辺全長の銅後退と部品退避、専用支持／切断が必要。自宅で曲げると実装済み1.2mm板へひずみが出る。第一案にしない |
| ミシン目なしの狭いFR-4ブリッジ | 工具切断はできても切断力・欠け・突起管理が難しい。試験で利点がある場合の代案 |

[JLCPCBパネル仕様](https://jlcpcb.com/help/article/pcb-panelization) ではEconomicはV-cut非対応でStandardが必要。[現行PCBA能力表](https://jlcpcb.com/capabilities/pcb-assembly-capabilities) は両方式のパネル上限250×250を掲げる。2mm中央溝だけなら16の芯寸法222×100、17は235×104.75。四周5mmレールを仮置きすると232×110／245×114.75で、17の横余裕は上限まで5mmしかない。中央捨て帯やレール拡幅で超える可能性を残し、最終パネルはピッチと実装工法決定後に審査する。メーカー納品時に分離されず一体で届く指定、左右2設計の扱い、パネル数量と完成ペア数量、タブ残し・rails・fiducial・tooling位置を製造レビューで確認する。価格・在庫・送料は取得していない。

## 6. D-021相当での配線見通しと両面実装

**2層を第一候補として進める価値がある。ただし既存板の局所改修で済む保証はなく、各Wingの内部は再配置と全体再配線を見込む。** #141では同じ21Hall＋3MUX＋GH14が信号0.10／電源GND0.30で両ピッチとも独立4指標0に達した。穴仮配置は外形内に収まり、孔縁間の最小材幅も4.09以上あるため、幾何上の即時不成立は見えていない。これが配線経路の空き幅を示すわけではなく、下面ランド・脚・via・zoneを重ねた後の成立は未証明である。

| 変化 | Stage 2以降の方針と成立条件 |
| --- | --- |
| φ1.70×42の追加 | 穴の全層逃げを先に定義。脚占有とdrill/copper制限を別に管理し、信号0.10・電源GND0.30を守る。衝突銅を温存しない |
| Hall下面化 | 実在DBZのpin1/2/3と面反転を照合し、raw線を対応MUXへ。Hall位置を配線都合でずらして磁石軸から逃がさない |
| 局所C下面化 | Hall給電／帰路を短く、穴で分断されたGNDを遠回りさせない。2層を信号逃げだけで使い切らず、GND連続性と戻り電流を確認 |
| MUX／GHは上面サービス帯 | サービス帯とキー域の経路集中、表裏遷移via、GH6帰線を評価。viaは0.60/0.30を保持。穴逃げ・下面部品でGND銅が細る箇所を抽出 |
| 右Wing | 右の部品pinを正しく再配置した別設計として配線・再資格確認。左のDRCを右へ転用しない |
| 自宅分離タブ | 無銅域を設計制約として最初から含め、後から配線を切るpanelizationを行わない |

工場で両面SMTを行う第一案では、上面MUX／GH／サービス部品と、下面21Hall＋局所Cが2回のpaste／搭載／リフロー対象になる。リフロー順、下面側保持・重量部品落下、ステンシル、検査治具、部品の影、L/R各BOM/CPLの原点・面・角度・pin1、両面fiducialを再審査する。下面部品でケースと分離治具の支持可能面が減る点も機構要件に含める。

[JLCPCB能力表](https://jlcpcb.com/capabilities/pcb-assembly-capabilities) の現行区分ではEconomicは片面搭載、Standardは両面搭載対応。従って**M1のEconomic費用・工程をこの両面案に引き継がない**。差額は部品追加だけでなく、両面工程・治具・検査・左右別設計パネルを含む別見積となる。全SMDを下面へ集約して片面PCBAにする代案は、GH方向／アクセス・MUX位置・支持面・配線が大きく変わるため別案として評価し、費用優先で標準着座やGH互換を崩さない。上面部品の手実装案も製品標準工程として今回採用しない。

電源は#141の抵抗網を新配線へ更新し、幅製造差±20%（0.30→0.24）、21センサー同時負荷、各局所GND上昇と帰路を含める。既存#141はWing入口4.75仮定で5mA/個の下限余裕が正でも、17・11mA包絡・125°C抵抗感度・最悪幅で4.4813となる。さらに#157案ではMainと2ハーネスの損失が加わり、17・127mA/枚の特定感度条件で4.5を割る。これらは今回の新板の計算結果ではなく、**0.30にすれば供給成立という推論を禁じる入力証拠**である。センサー変更時は負荷と磁気・ADCモデルを更新し、Main共通／左右枝・最遠Hall局所4.5–5.5（DRV5055候補時）、起動、EN排他、settling・ノイズ・温度・全押下を実測する。125°Cは抵抗感度でありシステムの運用温度承認ではない。

D-021はM1限定の既存決定なので、本Issueはver.Aへの採用案を提示する段階。配線不能時はまず穴／部品／サービス帯／パネルの制約と失敗箇所を提示し、2層→4層化、外形拡大、電源細線化、センサー軸移動を黙って行わない。

左／右でピッチを別に選んだり、結果待ちの間に16／17の製品PCBを先に作らない。本Stageで表左列を計画まで整理したのであり、基板作成を先行する指示ではない。M1は現行評価用のまま両ピッチを実測し、標準着座製品の距離曲線は別途再検証する。

後続Stageの開始条件と完了証拠は次の順とする。

1. **機械入力確定**：POのM1測定によるピッチ選択、製品キー配置、穴±5.08仮説／図の向き／脚公差、採用センサーと磁極方向を確認。単キー・隣接キー・親指の着座／回転／最大押下・抜差し工具を試験し、標準座りとキャップを確定する。
2. **設計条件合意**：外形・4穴維持範囲、t1.2・D-021相当、GH互換、#157の2Wing Main依存、両面PCBA、一体納品・自宅分離、無銅切断域、供給下限／性能受入れ値を作業条件へ記録する。
3. **Stage 2以降の実装**：正式フットプリントと回路を作り、穴／実装面・部品／全層逃げを先に検査して左右それぞれ配置・配線。配線後に未接続・異ネット接触・物理違反・転送不明差分の4指標0、クラス別幅、全銅層の穴・板端・タブ予約、GND連続性を再資格確認する。
4. **製造・実機確認**：表裏paste/mask、NPTH/PTH、BOM/CPL・面・回転・pin1、裸板／実装後パネルの強度と平面度、実物脚／下面部品／ケース、切断試験と分離後機能を確認。左右全42キーの距離・磁気・電源・ADC試験、2Wing Main/FWの受入れ証拠を揃えて製造判断へ進む。発注判断は別工程とする。
