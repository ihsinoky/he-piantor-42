# Issue #198 一体型ケース — Stage 1

17mm Wing Rev.2、Main Rev.4、UDB C3を配置した一体型トレーの基本形状を作成した。南辺はフラッシュな縁とし、基板上面より高い壁を置かない。全体は **308.917×140.968×15.200mm**、Ender-3 Proの220×220mmには一体で収まらない。X=3.5mmで左右2分割する案と、その形状データを用意した。

基板・ケースの公称幾何は成立する。**GHの実ケーブル経路は未解決**であり、A-2の長さ見積線をそのまま実配索に使えない。Stage 1の干渉検査結果としてこれを報告する。造形・発注・詳細設計は実施していない。

## 入力・再現方法

`.issue198-runtime/instructions-198-stage1.md`を全文読了した。指定の作業コピーが未作成だったため `.issue198-runtime/git` をローカルcloneとして作り、`issue-198-case-stage1`で作業した。スクラッチ・TMPDIRは `.issue198-runtime/` 配下、pushはPMOの担当とする。

成果物は [hardware/case/issue-198-stage1/](../hardware/case/issue-198-stage1/README.md)。[generate.py](../hardware/case/issue-198-stage1/generate.py)がCADと寸法JSON・上面SVGを生成し、[verify.py](../hardware/case/issue-198-stage1/verify.py)が出力を再読込して検証する。build123d 0.13.0を使用した。17mmが基準で、16mmも同スクリプトのピッチ・CSV切替で再生成・検証した。

- Wingは `hardware/case/issue-194-rev2/` の5頂点outline、keys、holes CSV。旧A-2に保存された矩形外形は使わない。ローカルX右・Y北、角度CCW、基板厚1.2mm。
- Mainは `issue-196-main-rev4-phasea2/geometry-plan.json` と Phase B最終 `inspection/final/main.kicad_pcb`。実基板から三角形・穴位置を取得し、59部品すべてのXY・角度をA-2と照合した。実基板hashは `b361a5a010a3ae2b08e5858735d46a5662112af4241ef55bab50d1ba3187b123`。外形はKiCad保存のµm量子化を含み、A-2との面積差は0.000035410mm²。
- UDBは[UDB-C-Legacy](https://github.com/Unified-Daughterboard/UDB-C-Legacy/tree/2ecdd7e0482ecbd3ffe9af04966ab3555f7fc33c/KiCad/C3)、commit `2ecdd7e0482ecbd3ffe9af04966ab3555f7fc33c`。指定された先行保存コピーのcommitを確認し、既に本リポジトリに保存された同版 `inputs/udb/c3.kicad_pcb` を読み取った。18×16.5mm、四隅R2、板厚1.6mm、取付穴φ2.2mmを抽出した。外形の円弧は32分割/90°（最大弦誤差0.000603mm）で表現した。寸法プレースホルダではないが、USB本体高さ・嵌合プラグ最大包絡は未確定。

全入力SHAは各 `dimensions.json`、CAD/STL/SVG等のSHAは `exports-sha256.json`。過去の基板・資格成果物は編集していない。

## 組立変換の導出と検証

組立は上面視X右・Y南、Z上。MainのKiCad座標から `X=X_K−100, Y=Y_K−70` とする。`c=√3/2`、左右の符号を `s=+1（左）/−1（右）` とし、Wing内側北角をローカル `(a,b)` に取る。

```text
X = −s + c(x−a) + s(y−b)/2
Y =      s(x−a)/2 − c(y−b)
M = [[c, s/2], [s/2, −c]]
t = (−s,0) − M(a,b)
17mm: 左(a,b)=(63.1,51.2)、右(a,b)=(−63.1,51.2)
16mm: 左(a,b)=(60.1,49.2)、右(a,b)=(−60.1,49.2)
```

17mmの平行移動は左 `(-81.246202979,12.790500674)`、右 `(81.246202979,12.790500674)`。内側北角はそれぞれ `(-1,0)/(1,0)` となる。行列の行列式−1はY北からY南への座標系変換による。部品・端子番号を鏡像コピーする操作ではない。右CSVと右専用definitionを使っている。

左右外向き軸は `(-c,-1/2)/(c,-1/2)`、内積−1/2なので120°、各Wingの回転は±30°。内辺の無限直線は `cX+Y/2+c=0`（左）、`−cX+Y/2+c=0`（右）となり、両ピッチで共通。南辺カットは北角・内辺ラインを動かさず、有限長と南側の角だけを変える。

| 検算項目 | 17mm | 16mm |
| --- | ---: | ---: |
| J2/J3→Wing GHの直線距離 | 113.017846 | 109.603532 |
| A-2折れ線の長さ | 156.341316 | 147.435562 |
| 30mm割当込み | 186.341316 | 177.435562 |
| 200mm候補との差 | 13.658684 | 22.564438 |

GH座標は現行Phase B definitionから読み、A-2の座標と一致することをassertした。17mm左は `(-124.789142919,14.209084961)`、右はX反転。したがって約186mmという見積と矛盾しない。南辺カット後にも旧折れ線の角を見積上の仮想点として残したため、これは実際の曲げ形状の証明ではない。

## 組立クリアランス

4枚の基板は共通の下面Z=10mmに置いた。Wing/Main上面Z=11.2mm、UDB上面Z=11.6mm。平面上の全6組で基板重複面積は0、STEPを再読込したケースを含む5 solid全10組でも体積干渉0だった。

| 組合せ | 17mm最小間隔 mm |
| --- | ---: |
| Main—Wing L/R | 1.999999 / 2.000000 |
| Wing L—R | 2.000000 |
| Main—UDB | 22.017949 |
| Wing L/R—UDB | 13.836320 |

Main—Wingの2mmとの差は最終基板の座標量子化。UDB—Wingは実R2外形で計算しており、A-2の矩形bbox評価13.104mmより広い。

UDB J2を `(0,−20)` に置き、元C3座標を `X=x−75.0045, Y=y−72.793−20` で変換した。UDB取付4点は `X=±7, Y=−34.25/−21.75`。実C3のMH2はGND接続PTHであり、4穴とも絶縁NPTHだとは扱わない。固定座は絶縁樹脂想定、ねじ・座金の導通は実機確認が必要。

## 基本形状と手のひら範囲

底厚2mm、基板外周とのXYクリアランス0.5mm、壁厚2mm。各基板の外形をオフセットした輪郭を結合し、UDB—Main間だけ内幅22mm（外幅26mm）の底・側壁で連続させたトレーである。Wing/Main接触ボスはφ4.5、UDB固定座φ3.5、M2用下穴φ1.7（仮定）。Wing各4点、Main3点、UDB4点の計15点で、基板穴とボス軸は同じ変換元から作成した。穴座標の独立逆変換も検算した。パイロット深さ8mmで底板を貫通しない。ねじ長さ・セルフタップ条件はStage 2。

Main J2/J3の原点 `(±15.5,43)` の直下に、幅2mm・長さ14mmの支持リブを底Z=2から基板下面Z=10まで配置した。Main外周から0.5mm内側で切り、基板下面へ接触させた。下面実装のないMainを支持する設計であり、締結荷重・リブ接触部の銅箔／レジスト損傷は未認定。

**手のひらはフラッシュな縁方式**。両Wingの南辺全長・内側面取り・両端コーナーを含む領域で、縁の最高Zを11.2mmに制限した。ローカル南端から北へ8mmの帯を上壁の除外領域とし、17mmで `y≤−27.498516`、16mmで `y≤−25.498516`。中央〜外側の広い余白を必ず含め、内側までフラッシュ領域を拡張した。南辺にはこの領域以外の高い壁を残していない。したがって別の南壁がスイッチから離れて立ち上がる箇所はない。低い縁の内面は基板から0.5mmで、同高の張り出しを側方に2mm設けた。大R加工は今回採用していない。

南辺以外の上壁は最高Z=15.2mmとし、仮キーキャップ包絡＋0.25mmの領域を壁から切り欠いた。基板より下の外周形状とボスを保持したまま、キーに近い高い壁だけを詰める。SVGの桃色部分がフラッシュ帯、茶色が上壁、青破線が分割線。

GHの見積線は旧Wing南内角を通るため、カット後の新輪郭と整合しない部分がある。長さ確認に使えても実ハーネスの中心線には採用できない。Main—Wing間2mmも、φ2ケーブル＋公差やR5の折返しを保証する間隙ではない。下面には8mmの空間があるが、リブ・ボス・下面部品と、上面嵌合部から下面へ入る移行経路が未検証なので、下面配索を解決策と断定しない。Stage 2ではT2を避ける実3D経路・必要な局所溝／外側経路を作り、200mmで足りるか再計算する。

SHはMain側北向き、UDB側南向きというA-2の出口を保つ。J4サービス域はA-2で確保した予約域で、余長の折返し・ラッチの操作指の立体包絡は今回の基板STEPに含めていない。開放上面のため高さ上限は設けていない。

USBスロットは天井を作らないのでブリッジ不要だが、基板上のFab線は最大公差付きの嵌合面寸法ではない。Fab参照位置から北外壁までは4mmの引込みがあり、実プラグのオーバーモールドが幅12mmに通るか、高さ方向で底縁に当たらないかは実物で確認する。UDB基板外形・穴は確定入力、プラグ開口の採否は未確定として区別する。

キーキャップ17mm正方形・高さ14mm、GH嵌合7mm、R5、φ2、下面部品3mmは設計予約であり、部品メーカー保証最大値ではない。16mm成果物は再生成可能性の検証で、仮17mmキーキャップの隣接キー同士の適合を保証しない。両ピッチの実キーキャップ外形・スイッチ軸高さ・可動範囲は現物／図面で認定する。

## 印刷可能性と分割案

底Z=0をベッドに置く。底・垂直壁・ボス・リブは下から連続して積層でき、今回のUスロットには屋根がない。サポート不要を想定する基本形状だが、薄肉切欠き部・反り・積層方向・材料の最終スライスは未実施。造形実行・発注はPOゲートとする。

| ピッチ | 全体 XYZ mm | 左ピース XYZ mm | 右ピース XYZ mm |
| --- | --- | --- | --- |
| 17mm | 308.917×140.968×15.200 | 157.959×140.968×15.200 | 150.959×140.968×15.200 |
| 16mm | 294.525×134.490×15.200 | 150.762×134.490×15.200 | 143.762×134.490×15.200 |

回転配置も0〜90°を0.1°刻みで調べた。各出力の `printing.best_sampled_square_mm` と、角度サンプリング誤差を半ステップから保守的に差し引いた `square_lower_bound_mm` で、220mm角へ一体で入らないことを検証した。17mmの必要正方形辺の下限は241.900mm、16mmは230.700mmだった。各分割ピースはXY軸のままで220mm角に収まり、ブリム5mmを周囲に加えても余裕がある。

分割面X=3.5mmはMain北穴X=0とUDB右穴X=7のボスを避ける。接合は下面の20×12×3mmプレート2枚をY=−8、55付近に置き、各2本のM2ねじで左右の底を結ぶ案。外周のシルエットと上面操作は一体型のまま保つ。プレート自体も220mm角内に入る。分割STEP/STLは突合せ面までを実装した形状で、接合プレート・下穴・位置決めダボ・反り止め・底足は未実装。下面プレートの逃げに3mm以上の脚高、床ねじ部には局所厚肉または受けナットを検討する。保持力・公差を決める詳細はStage 2である。

## 検証とPO判断が要る事項

17mm/16mmそれぞれで、CADの有効性・1 solid、分割後の各1 solid、STEP再読込、STL全辺の2面共有（非多様体辺0）、STEP/STL体積差0.1%未満、左右分割体積和、入力・出力SHA、CSV穴座標の逆変換、組立5 solidの全10組の体積干渉を検証した。結果は各 `verification.json` に保存した。2D上面図は各 `review.svg`、寸法・予約・未決事項は各 `dimensions.json` に収録した。

PO/PMOへ次の判断を引き継ぐ。

1. 南辺全長をフラッシュとする処理と、現状の外周・高さの採否。
2. 2分割＋下面ねじ接合の採否。一体造形を優先する場合は大型造形機へ変更する判断。
3. GHのT2回避経路と、上側／下側／局所外側溝の選択。200mmハーネスの機械経路・最大曲げ・着脱確認が終わるまで造形GOにしない。
4. 実スイッチ／キーキャップと下面実装部品のZスタック、GH/SH実ハウジング・USBプラグ包絡、ねじ・材質・印刷公差の確定。
5. Stage 2詳細設計への移行と、実物での嵌合確認。その後の造形・発注は別途PO判断。
